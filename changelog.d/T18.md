## Для разработки

- `lib/domain/grid/reading_order.dart`: `ReadingOrder.of(geometry, columns:, rows:, start:)` — ряды плетения по запросу (`row(i)`, `allRows`, `cells`). Станок: ряды сетки, направление одно; кирпичный стежок: ряды сетки, направление чередуется; мозаика/пейот (`drop: 1`): ряд = столбец, первый ряд — два первых столбца зигзагом (порядок по Y центров ячеек), рядов на один меньше столбцов; нечётная мозаика — пустая ячейка (`0`) в конце второго столбца. Пейот с `drop > 1`: каждый столбец — ряд (уточнит T35). `ReadingStart` — угол начала (4 варианта), `RowDirection` — стрелка (→ ← ↓ ↑).
- `lib/domain/grid/word_chart.dart`: `WordChart.forRow` / `WordChart.build` — серии `WordRun(colorIndex, count)`; склейка только внутри ряда, пустая ячейка не бусина и рвёт серию.
- `lib/domain/materials/`: интерфейсы `MaterialEstimator`, `MaterialEstimate`, `MaterialLine` (для `FlossEstimator` в T44) и `BeadEstimator` → `BeadEstimate`: штуки и граммы по цветам (вес — `BeadSize.weightGrams`), запас `reserve` (по умолчанию 10%, 0–1), округление вверх по каждому цвету. Цвет сетки вне палитры — `ArgumentError`.
- Эталонные схемы (станок, кирпичный, пейот чётный и нечётный) в `test/domain/grid/reading_fixtures.dart` составлены вручную, word chart выписан с рисунка вручную, не из кода: реальных книжных примеров в репозитории нет.
- Миграций БД нет.
