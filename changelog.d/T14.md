## Для пользовательницы

- Схемы, которые рисуются в приложении, теперь есть где хранить: сетка, цвета и размер бусины сохраняются вместе с работой. Рисовать пока нечем, но всё готово к появлению редактора.
- Отметки пройденных рядов и место, где остановилась, запоминаются для каждой схемы отдельно.
- Копия работы забирает свою сетку и палитру, а отметки начинаются заново; при удалении работы схема удаляется вместе с ней.

## Для разработки

- **Миграция БД v5 → v6** (`schemaVersion` = 6, шаг `from5To6`): таблицы `grid_patterns` (одна на проект; геометрия + `geometry_drop`, размеры, `cell_metrics` JSON, `current_row`/`current_bead`, `cells` BLOB + `cells_codec_version`, пустые пока `layers`/`layers_codec_version` для T37/T38), `pattern_colors` (снимок палитры: `rgb`, `components` JSON, `finish`, `symbol`) и `grid_progress_rows`. Колонка `drop` из data-and-sync.md названа `geometry_drop`: `DROP` зарезервировано в SQL. Дамп `drift_schema_v6.json`, тест миграции с данными.
- Домен `lib/domain/grid_pattern/`: `GridPattern` (+ `GridLayersBlob` — слои хранятся как непрозрачные байты и версия кодека и не теряются при правке), `GridPatternSummary`, `GridProgress`, `GridPatternRepository` (схема + палитра одной транзакцией, `watchByProject`, `summaryByProject` без чтения BLOB), `GridProgressStore` (отдельный интерфейс: T38 добавит прогресс по клеткам, не трогая репозиторий схем), `CellMetricsCodec` (виды `bead`, `custom`; `fabric` добавит T36), `GridGeometryCodec`.
- Use cases: `CreateGridPattern` (проект `contentKind=grid`, откат проекта при ошибке записи), `SaveGridPattern`, `MarkRow`, `UnmarkRow`, `SetCurrentBead` (номера рядов и бусин проверяются по сводке схемы). `GridPatternContentCloner` и `GridPatternContentCleaner` подключены в DI к `DuplicateProject` и `DeleteProject`.
- Данные: `DriftGridPatternRepository`, `DriftGridProgressStore`, `GridPatternsDao`. Отметка ряда — строка с надгробием при снятии (при слиянии — множество). При уменьшении схемы отметки и позиция за её краем снимаются.
- Данные для миниатюры библиотеки — сама `GridPattern` из `getByProject`; рисовать её будет `presentation` (T15), провайдер миниатюр подключит T05.
