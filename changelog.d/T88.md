## Для пользовательницы
- В мастере «Схема из фото» можно задать высоту вышивки и выбрать: обрезать фото под нужный формат или оставить поля. В редакторе обрезки появятся кнопки готовых пропорций (2:3, 3:4, 4:3 и другие): рамка стоит на месте, двигается и масштабируется только фото.

## Для разработки
- Архитектура T88a: высота хранится в клетках (`rows`, null = по фото), подогнанная рамка нигде не сохраняется (считает `FramePlanner`), поля добавляются в конце конвейера (`PatternFrame.pad`). Реализовано (T88a): `ImageToGridSettings.rows`/`fit` (`FrameFit`), `withFabric` (смена канвы сохраняет высоту в см), `effectiveRows` вместо `rowsFor`, `GridSizing.rowsForAspect`/`columnsForAspect`, `CropFit` (`fitAspect`, `panLocked`, `zoomLocked`, `rotateAspect`), `FramePlanner.plan` → `FramePlan` (внутренняя сетка, смещение, чётность peyote/brick), `PatternFrame.pad` последним шагом `ImageToGridPipeline.run` (запрос несёт `frame`; ключ кеша стадий не меняется), ключи рецепта `rows`/`fit` (пишутся только при заданной высоте, `v` остаётся 1).
- Реализовано (T88b): редактор обрезки перенесён в `presentation/common/crop/` (`crop_editor.dart`, стеклянная панель `crop_presets_panel.dart`). `showCropEditor` остался обёрткой (`CropRect?`, без панели: импорт книги как раньше), новая `showCropEditorResult` возвращает `CropEditorResult(crop, aspect)` (`aspect` null — рамка свободная) и принимает `presets`, `sizeLabel`, `targetAspect` (ширина / высота в долях физического размера; редактор не знает про `ImageToGridSettings`, связь с `rows` — T88c). Чип фиксирует рамку по центру области, фото двигается и масштабируется через `CropFit.panLocked`/`zoomLocked`, `fitAspect`/`rotateAspect` для выбора и переворота; касание края выключает чип. Жесты переведены с `onPan` на `onScale` (один палец — перетаскивание края), точка касания читается через `Listener` (порог жеста не уводит палец от зоны захвата), колесо мыши — `PointerScrollEvent`, щипок трекпада — тот же `onScale`. Ширина окна от 700 pt: чипы под фото, внизу «Сбросить», «Отмена», «Готово».
- Реализовано (T88c): строка «Высота» в разделе размера мастера «Схема из фото» (вышивка: см с шагом 5 см до `maxStitchHeightCm`, бисер: ряды 8…240), таблетка «По фото» (`clearHeight`), сегмент «Обрезать» / «Оставить поля» с пояснением (приглушён, пока высота по фото), строка «Обрезка…» с размером кадра или «Рамка не задана». Кубит: `setHeightCm`, `setRows`, `clearHeight`, `setFit`, `setCropResult(crop, aspect:)` (чип → `rows = GridSizing.rowsForAspect` и рамка, свободная рамка → `rows = null`). `ImageWizardState.sourceAspect` + `plan`/`effectiveCrop`/`planOf`: подогнанная рамка нигде не хранится, считается `FramePlanner`; кубит держит приватный `_appliedCrop` лишь как ключ подготовленной картинки. Картинка заново готовится (`_syncImage`) по `effectiveCrop` внутри отложенного расчёта (на каждый тик ползунка процессор не вызывается; черновики по устаревшей картинке не считаются); `PreparedFrame` кисти и сравнение «до/после» используют ту же рамку. `ImageToGridSettings.supportsMargins` (нет у станка и квадрата): `setFit(margins)` и смена техники принудительно возвращают `crop`. `setCraft` сбрасывает высоту; пробы подсказки размера считаются без высоты. Предпросмотр: `FrameOverlayPainter` (штриховка полей с пунктирной границей схемы, рамка кадра), подписи «Поля: штриховка» и «Рамка: … Лишнее уйдёт».
