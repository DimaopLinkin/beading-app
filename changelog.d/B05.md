## Для пользовательницы

- Если в схеме уже есть отметки прогресса и вы вставляете или удаляете ряд, отметки остаются на своих клетках: вставленный ряд без отметок, отметки удалённого ряда пропадают, остальные сдвигаются. «Отменить» и «Вернуть» сдвигают их обратно (отметки удалённого ряда при отмене не возвращаются).

## Для разработки

- `ShiftProgress` (`lib/domain/grid_pattern/use_cases/shift_progress.dart`) пересчитывает отметки через обычные записи хранилищ (ряды бисера: `markRow`/`unmarkRow`/`setCurrent`; вышивка: `writeBlocks`), поэтому синхронизация не меняется. `EditorSnapshot.edit` хранит `ShapeEdit`, которым получено состояние, чтобы «Отменить»/«Вернуть» применяли обратный сдвиг. Для пейота ряд плетения = столбец − 1, вставка у двух первых столбцов отметки не сдвигает. Побочно в аудите A09 отмечены исправленными A09-06…09, A09-14.
