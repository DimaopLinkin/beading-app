## Для пользовательницы

- Новый способ начать работу: «Схема из картинки». Выбираешь фото, обрезаешь, и приложение само собирает схему для плетения.
- Схема пересчитывается на глазах, пока меняешь технику, размер бисера, ширину и число цветов. Если зажать схему пальцем, виден исходный снимок: можно сравнить «до» и «после».
- Цвета можно взять из каталога бисера (тогда схему можно собрать из магазинных цветов) или подобрать свободно. Переключатель «Плавные переходы» лучше передаёт оттенки.

## Для разработки

- Мастер: `lib/presentation/image_to_grid/` (`ImageWizardCubit`, `ImageWizardScreen`, маршрут `/generate/image`), пункт «Схема из картинки» в реестре T05 только для бисера (`lib/app/library_entries.dart`). Выбор источника и обрезка переиспользуют `BookImageSource`, `ImageProcessor` и `showCropEditor` из импорта книги.
- Предпросмотр: дебаунс 300 мс, расчёт в `ImageToGridRunner`; изолят не отменяется, поэтому устаревший результат отбрасывается по номеру расчёта. Сохранять можно только схему текущих параметров.
- Домен: `ImageToGridSettings` (параметры и сборка `ImageToGridRequest`, шаги T47–T49 передаются в `steps`), `geometryForTechnique`, `paletteFromGenerated` (цвета вне каталога получают ссылку `custom` + `#RRGGBB`), `CreatePatternFromImage`, интерфейс `ImageDecoder` и `UiImageDecoder` в data (уменьшает картинку до 1024 px).
- Маска важности пока не передаётся: её подключит T48.
- Миграций БД, новых зависимостей и разрешений нет.
