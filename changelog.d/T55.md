## Для пользовательницы

- Пока ничего не меняется: фон и обводка включатся в мастере вместе с распознаванием объекта на фото (T48).

## Для разработки

- `BackgroundStage` (`BackgroundMode` keep/simplify/remove, обводка): работает после всех шагов по маске объекта на клетках (`subjectCellsFrom`, клетка — объект, если под ней ≥ 50 % пикселей маски). «Упростить» оставляет вне маски ≤ 3 цветов палитры (жадный выбор по ΔE2000 до цвета клетки, затем мажоритарное сглаживание), «убрать» даёт пустые клетки, обводка — клетки объекта с соседом-фоном (по `CellNeighbors`, пейот и кирпич учтены), самый тёмный цвет палитры или добавленный тёмный (с учётом каталога).
- `ImageToGridRequest.subjectMask` (Uint8List на пиксель, 0 — фон; формат `ImageMaskSet.subject` из T48), `background`, `outline`, `withBackground`; без маски настройки не действуют. `effectiveImportance` снижает вес фона (×0,5 / ×0,05) при выборе палитры.
- `ImageToGridSettings.background/outline`, `toRequest(subjectMask:)`. Подключение мастера (скрыть настройки без маски, передать `subjectOrPerson`) — вместе с T48.
- Галерея: варианты `t55-simplify/remove/outline` с заменителем маски `standInSubjectMask` (плоский фон по рамке кадра, иначе эллипс); базa метрик дополнена. Миграций БД нет.
