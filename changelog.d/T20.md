## Для пользовательницы

- В «Моих работах» появилась кнопка каталога цветов: можно листать бисер по производителям и искать по номеру или названию.
- Нажми на цвет в каталоге, и приложение покажет пять самых похожих с процентом сходства: удобно, если нужного нет в магазине.
- У схемы из приложения в меню долгого нажатия есть «Материалы»: сколько бусин и граммов каждого цвета нужно, можно с запасом.
- Список материалов можно отправить кому-нибудь или записать в заметки кнопкой «Поделиться списком».

## Для разработки

- Домен: `ColorSimilarity` (ΔE2000 → проценты и словесный уровень; шкала для людей, не стандарт), `FindSimilarColors` (ближайшие без самого цвета, по всем брендам материала), `LoadProjectMaterials` (схема проекта → `BeadEstimate`; для `CustomCellMetrics` возвращает `ValidationFailure`: вес неизвестен, ниточный расчёт добавит T44), интерфейс `TextSharer` (`lib/domain/sharing`).
- Данные: `SharePlusTextSharer` на `share_plus` — **новая зависимость**, плагин для iOS и macOS (разрешений в Info.plist не требует). Нативную сборку в CI не гоняем: проверить `flutter build macos` и `flutter build ios` при подготовке релиза.
- Presentation: `CatalogCubit` + `CatalogScreen` (маршрут `/catalog`; параметр `material` готов под каталог ниток T36, первой вкладкой открывается бренд из настройки), `MaterialsCubit` + `MaterialsScreen` (`/projects/:projectId/materials`), `MaterialsFormat` (числа и текст «Поделиться» по эталону в `test/presentation/materials/materials_format_test.dart`). Общие виджеты `PillChip` (вынесен из `FilterChipBar`) и `ColorSwatchView`.
- Библиотека: кнопка каталога в шапке (`onOpenCatalog`) и пункт «Материалы» в меню долгого нажатия бисерных схем из приложения (`onOpenMaterials`). Экран проекта появится в T15/T19: туда же можно перенести вход в материалы.
- Дизайн: макета 07-catalog-materials пока нет, экраны сделаны по UI kit и стилю библиотеки; после приёмки макета возможна доводка.
- Миграций БД нет.
