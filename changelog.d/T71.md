## Для пользовательницы

- Экран «Схема из картинки»: ползунки ширины и числа цветов стали во всю ширину, рядом с названием появились кнопки «−» и «+»; если нажать на число, его можно ввести с клавиатуры.
- У вышивки по умолчанию теперь 60 см и 50 цветов. Размер, подсказанный по фото, для вышивки только предлагается кнопкой «Применить».
- Детальность идёт по порядку: «Проще», «Средне», «Детально», «Как на фото». По умолчанию выбрано «Детально».
- Контуры по умолчанию выключены, бленды из двух ниток включены.
- Под предпросмотром к размеру схемы добавлены число цветов и, у вышивки, канва (например, «Аида 14»).
