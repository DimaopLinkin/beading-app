## Для пользовательницы

- Вышивки из фото снова получаются сочными: красные, оранжевые и коричневые не бледнеют и не становятся «розовыми». Автоподъём теней теперь трогает только по-настоящему тёмные места (там, где в каталоге нет ниток), а не все средние тона. Если схему когда-то считали и она вышла бледной — откройте её на правку, схема пересчитается заново.

## Для разработки

- `ShadowLift.fadeL` 60 → 40 (вес подъёма сходит на нет к L = 40, быстрый отсев по Y пересчитан), `penaltyPerGamma` 3 → 5: автоподбор поднимает тени только при явной пользе. Кривая T87 с порогом 60 при a, b без изменений поднимала светлоту красных (L ≈ 45) на 6–11 пунктов и давала бледные, «розоватые» тона на тёмных фото.
