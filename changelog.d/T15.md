## Для пользовательницы

- В приложении появилась основа для показа схем по сетке: бусины рисуются цветом, с подсказкой отделки (глянец, матовая, металлик, прозрачная), а по желанию на каждой бусине виден знак палитры.
- Схему можно увеличивать щипком и двигать пальцем. На станке, в пейоте и в кирпичном стежке бусины лежат так, как лежат в работе.
- Текущий ряд обведён двойным кольцом (чёрным и белым), которое видно на любых бусинах, а слева у края стоит метка с номером ряда. Пройденные ряды чуть притушены.
- Каждая пятая (или десятая, для вышивки) линия сетки жирнее, чтобы не сбиться при счёте.

## Для разработки

- Миграций БД нет.
- `GridGeometry`: `cellSize` (кирпичный стежок меняет ширину и высоту местами) и `visibleCells` (диапазон `CellRange` для отрисовки только видимой области); у геометрий появилось сравнение по значению.
- `lib/presentation/grid_pattern/`: `GridPatternView` (`InteractiveViewer`, `onCellTap` и `onCellLongPress` в координатах ячейки через `GridScene.cellAt`), `GridScene` (мм → пиксели, один источник раскладки для рисования и касаний), `GridLayerCache` (`Picture` на блок 32×32 ячейки, строятся лениво для видимых блоков; подсветка в кеш не входит), `GridOverlayPainter` (вуаль, двойное кольцо, метки), `GridThumbnail` для карточки библиотеки, `GridViewOptions` (символы, жирная линия каждой N-й, подсветка).
- Цвета подсветки пока в `GridColors` (значения из принятого дополнения UI kit 01b); после мержа T01b перевести кольцо на токен `rowRing`.
- Golden-тесты: три геометрии × обе темы × режим символов, маркер ряда, миниатюра.
