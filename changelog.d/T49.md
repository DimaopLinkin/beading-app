## Для разработки

- `OutlineBackstitch` (`lib/domain/image_to_grid/outline_backstitch.dart`): контуры-бэкстич из картинки для вышивки. Берёт границы маски объекта (T48/T55, маска по клеткам) и контрастные границы рабочего изображения (ΔE2000 между средними цветами соседних клеток, при разных цветах крестиков), собирает цепочки, отбрасывает короткие обрывки, упрощает Рамером — Дугласом — Пекером, режет стежки длиннее `maxStitch`. Результат — `List<LineStitch>` для `StitchLayers.lines`.
- В конвейер и мастер шаг подключит T46; миграции БД нет.
