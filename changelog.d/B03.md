## Для пользовательницы

- Бусины, которые вы добавили на вышивку, теперь попадают в расход ниток: на экране «Нитки» появился раздел «Бисер на вышивке» с числом бусин по артикулам, и он есть в тексте при «Поделиться».

## Для разработки

- `FlossEstimate.beads` (`BeadPurchaseLine`) считает бусины слоя `PointStitch.bead` по ссылке каталога, запас округляется вверх; экран и текст «Поделиться» показывают раздел, если бусины есть. Закрывает остаток T40: «слой бусин не попадал в список покупок».
