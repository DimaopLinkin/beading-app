## Для разработки

- База drift `AppDatabase` (schemaVersion 1, `lib/data/db`): таблица `settings` (key PK, value) и миксин служебных колонок синхронизации `SyncColumns` (`created_at`, `updated_at`, `deleted_at`, `device_id`, UTC мс) плюс `UuidIdColumn` для будущих таблиц. Файл базы — в Application Support (`beading.sqlite`).
- `SettingsRepository` теперь типизированный: `read/write/reset/watch` по `SettingKey<T>`. Ключи в `SettingKeys`: тема, «Не гасить экран» (по умолчанию вкл.), режим символов, `defaultBeadBrand` и `defaultFlossBrand` отдельно, имя («Настя») и особые даты. Сброс — надгробие (`deleted_at`). Репозиторий сам ставит `updated_at` и `device_id`.
- `DeviceIdProvider`: идентификатор устройства создаётся один раз и хранится в `settings` под ключом `local.deviceId` (префикс `local.` = не синхронизировать).
- Миграции: `build.yaml` (`drift_schemas/`, `test/data/db/migration/`), дамп схемы v1, сгенерированные утилиты и тест v1. При `schemaVersion++` запускать `dart run drift_dev make-migrations`.
- Заменено: `InMemorySettingsRepository` из T01 удалён, `ThemeModeCubit` читает `SettingKeys.themeMode`. `configureDependencies` и `bootstrap` принимают базу (в тестах — `NativeDatabase.memory()`).
- Зависимости: `path`, `path_provider`, `sqlite3` (прямые). `analyze.sh` не форматирует `*.g.dart`; сгенерированный `test/**/generated` исключён из анализа.
