## Для пользовательницы

- Проект-инструкция открывается: крупный шаг с фото, текстом и бусинами («3 × A»), кнопки «Готово, дальше» и «Назад» внизу под большим пальцем, свайп по тексту тоже листает шаги.
- Повторы видны: «повтор 4 из 10» с полосками, а для «до нужной длины» кнопка «Достаточно».
- Список шагов по секциям: касание строки переходит к шагу. Место, где остановилась, запоминается и после перезапуска.
- На последнем шаге можно отметить работу законченной.

## Для разработки

- `presentation/steps/`: `StepsWorkCubit`, экран работы, лист списка шагов, общие виджеты `BeadChip`, `RepeatSegments`, `StepImagesPager` для редактора (T33d). Маршрут `AppRoutes.steps(id)`, ветка `ContentKind.steps` в библиотеке.
