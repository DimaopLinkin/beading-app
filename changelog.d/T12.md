## Для разработки

- `lib/domain/palette/`: `Rgb` (hex, среднее в линейном RGB для смешанных нитей), `Lab` (sRGB → XYZ D65 → Lab) и `deltaE2000`, проверен на 34 эталонных парах Sharma (2005) с точностью 1e-4.
- `NearestColorMatcher<T>` — top-N ближайших по ΔE2000 к любому каталогу (функция `rgbOf`), Lab каталога считается один раз; T13 подключит свою запись каталога.
- `PatternColor` — снимок цвета схемы: `rgb`, `name`, `components` (1–2 `CatalogRef`), `finish`, `symbol`; `PatternColor.blend` для смешанной нити.
- `PaletteSnapshot` — неизменяемая палитра; `add/rename/replace/remove/merge` возвращают `Result<PaletteEdit>` с `PaletteReindex` (старое значение сетки → новое, `0` — ячейка очищается), от `Grid` (T11) не зависит. Значение сетки `n` = `palette[n - 1]`, не больше 65535 цветов.
- `SymbolAssigner`: A–Z, цифры, знаки, фигуры, греческие буквы — 120+ одиночных символов; новый цвет получает первый свободный, выданные не меняются.
- Каталог бисера и таблица `catalog_colors` — T13, не здесь.
