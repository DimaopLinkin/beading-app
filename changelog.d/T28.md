## Для пользовательницы
- Появилась синхронизация между устройствами: в «Настройках» → «Синхронизация» входишь по почте и паролю, и проекты, прогресс и запас ниток совпадают на iPhone и Mac. Синхронизация идёт при запуске, при возвращении в приложение, раз в минуту и по кнопке «Синхронизировать сейчас». Без входа приложение работает как раньше.

## Для разработки
- `SyncCubit` (вход, циклы `SyncEngine`, статус, таймер), `SyncScreen`, `SyncModule` (граф ADR-0007), `SupabaseSyncSession`, `SecureSessionStorage` (сессия в Keychain; macOS без data protection keychain).
- Адрес и ключ идут через `--dart-define=SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`; без них `AppDependencies.sync == null`.
- macOS: entitlement `com.apple.security.network.client`.
- Не сделано: realtime-пробуждение, правка после смены аккаунта на устройстве (сейчас только сообщение), переключатель «страницы книг», счётчик места.
