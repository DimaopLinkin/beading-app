## Для пользовательницы

- Схемы вышивки из файлов `.oxs` (их сохраняют MacStitch, WinStitch, MobiStitch, Embroiderly и другие программы) можно открыть в «Бисере»: выбрать файл в «Импорте» в настройках, открыть из «Файлов» или отправить через AirDrop. Появится проект «вышивка крестиком» со схемой, нитками (бренд и номер), канвой, неполными крестиками, бэкстичем и узелками.
- Если в файле есть то, чего приложение не умеет (большие стежки, треугольники), они пропускаются.

## Для разработки

- `OxsDecoder` (domain) и `XmlOxsDecoder` (data, пакет `xml`) разбирают файл по спецификации embroidery-space/xsp-specs (MIT; чужой код не используется); `OxsConverter` переводит в `Grid`, `PaletteSnapshot`, `StitchLayers`, `Fabric`; `ImportOxs` создаёт проект через `CreateGridPattern`. `DataTransferCubit` направляет файлы `.oxs` в `ImportOxs`, остальные — в `ImportBiser`.
- Допущения: координаты стежков и линий решётки — с 1, шаг линий 0,5; ¾-стежок приводится к виду приложения по названию стороны из спецификации; цвет без номера бренда получает бренд `OXS`. Проверено только на фикстуре, написанной по спецификации: файлов из MobiStitch или Embroiderly в проекте ещё нет.
- Описание типа `com.dimaoplinkin.beading.oxs` добавлено в `Info.plist` iOS и macOS (импортированный тип, роль «просмотр», ранг «альтернативный»); работу на устройстве ещё не проверяли.
- Экспорт `.oxs` (NICE-X5) не входит в задачу.
