## Для пользовательницы
- Большие плотные вышивки больше не тормозят: на экране работы отметки, мазок и область идут плавно даже когда залита большая часть схемы, а зум и сдвиг всей схемы стали быстрее.
- В мастере схемы из фото предпросмотр большой и плотной схемы больше не подвешивает экран, а устаревшие расчёты при движении ползунка не копятся.

## Для разработки
- `GridViewOptions.doneCells` теперь `CellProgress`, а не набор клеток; вуаль «сделано» вынесена из `GridOverlayPainter` в `GridDoneLayerCache` (`Picture` на блок отметок 16×16, перестраиваются только изменившиеся блоки, слияние клеток ряда).
- `CellProgress.withCells` копирует только затронутые блоки, равенство и хеш без копирования блоков; `StitchCounters.tally` считает цвета, итог и блоки 10×10 за один проход по битам.
- `GridLayerCache` получил обзорный режим (`flat`): клетка на экране меньше 4 пикселей рисуется заливкой без крестиков, блеска и знаков; вид переключает его по зуму (гистерезис 4 / 5,5 px) и по размеру предпросмотра.
- `IsolateImageToGridRunner`: один расчёт в изоляте, ждущий запрос заменяется новым (`RunSuperseded`).
