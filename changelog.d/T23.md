## Для пользовательницы

- Можно создать узор из готового шаблона: полосы, зигзаг, ромбы, шахматка, градиент или бордюр.
- Узор сразу виден целиком: меняешь размер, цвета и параметры, а картинка перестраивается.
- Цвета выбираются из каталога бисера; градиент сам подбирает промежуточные оттенки.
- Готовый узор сохраняется новым проектом и появляется в «Моих работах».

## Для разработки

- Экран `lib/presentation/pattern_template` (`PatternTemplateCubit`, `PatternTemplateScreen`) только на нативных компонентах: `CupertinoListSection`/`CupertinoListTile`, системный лист `showCupertinoSheet` для выбора цвета, `CupertinoActionSheet` для выбора техники, бисера, симметрии и направления, маршрут `/generate/template`, пункт `pattern-template` в `NewProjectRegistry` для бисера.
- Опирается на `PatternGenerator` (T22): в градиент передаётся `catalog` — цвета каталога выбранного бренда (настройка «производитель по умолчанию»).
- Зеркальная симметрия в генераторе идёт по индексам, в пейоте и кирпичном стежке она неточная: на экране под выбором симметрии есть пояснение.
- Узор сохраняется через `CreateGridPattern` (проект `contentKind = grid`, палитра со знаками через `PaletteSnapshot.add`). Миграций БД, новых зависимостей и разрешений нет; новые строки в ARB (`template*`).
- Макета 2.7(2) в `docs/design/accepted` пока нет (промпт `08-generation` в очереди): экран собран из компонентов UI kit, после приёмки макета возможна подгонка.
