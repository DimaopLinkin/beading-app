## Для пользовательницы

- Схему из книги теперь можно открыть и плести по ней: страница занимает почти весь экран, увеличивать можно щипком, до восьми раз.
- Поверх страницы лежит цветная «линейка» текущего ряда, а всё, что выше неё, слегка притушено. Кнопки «Назад» и «Следующий ряд» внизу крупные, под большой палец; ряд можно также листать смахиванием по номеру ряда (на Mac — стрелками вверх и вниз).
- Линейку можно настроить: высота, на сколько она сдвигается за раз и цвет подсветки. Страница сама подстраивается так, чтобы линейка не пряталась за панелями.
- Если в схеме несколько страниц, между ними переключаются кнопкой «Стр. 1 из 3». У каждой страницы своя линейка и свой масштаб.
- Приложение помнит, где ты остановилась: открытая страница, линейка и увеличение сохраняются сразу. Работа над схемой переводит её из «Идеи» в «В работе».
- Заметки к работе открываются снизу по кнопке с листочком.

## Для разработки

- **Миграция БД v5 → v6** (`schemaVersion` = 6): таблицы `page_work_states` (линейка и вид страницы; `id` = id страницы) и `book_work_states` (открытая страница; `id` = id схемы). Дамп `drift_schema_v6.json`, тест миграции с данными. Надгробие схемы (`ImagePatternsDao.tombstoneByProject`) ставит надгробия и запомненной работе.
- Домен `lib/domain/image_pattern/book_work`: `RulerState` (позиция, высота, шаг и ряд в пикселях страницы; границы страницы), `PageViewport` (зум/сдвиг, `revealing` — автоподстройка вида под панели), `PageWork`/`BookWork`, `BookWorkRepository`, use case `RecordBookProgress` (`idea → inProgress` + `TouchProject`).
- `FileStore.read` (новый метод интерфейса) нужен экрану для показа картинки страницы.
- `BookWorkCubit`: изменения применяются сразу, запись на диск с debounce 250 мс и принудительно при закрытии; незаписанное при сбое возвращается в очередь. Экран `/book/:projectId` (`BookWorkScreen`, `InteractiveViewer` до 8×, листы линейки, заметок и страниц на `GlassSheet`). После импорта из книги библиотека сразу открывает работу; T05 должен открывать её же (`AppRoutes.bookWork`) из карточки проекта.
- Копия проекта (`DuplicateProject`) начинает работу над схемой с чистого листа: состояние линейки не клонируется.
