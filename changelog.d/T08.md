## Для пользовательницы

- Изредка приложение будет говорить тебе что-нибудь приятное: небольшая плашка сверху экрана на пять секунд. Её можно смахнуть вверх, она не закрывает кнопки внизу.
- Особенно часто радуется, когда ты закончила работу, и в особые даты.

## Для разработки

- Домен `lib/domain/easter_eggs`: `AppEvents` (шина событий: `AppStarted`, `ProjectCompleted`, `RowsCompleted(total)`, `LongSession`, `SecretTapped`), чистая `EasterEggPolicy` (шансы, тишина 2 минуты, один за сессию, интервал 3 дня, ротация текстов без повторов, особые даты раз в день), `EasterEggService` (слушает шину, пишет журнал, отдаёт поток `shown`; любая ошибка = промолчать), `LongSessionWatcher` (событие через 90 минут).
- Гарантированные (100%) триггеры «готово», особая дата и секрет обходят ограничения редкости; в 3-дневный интервал входят все группы, кроме секрета.
- Тексты: `assets/compliments/ru.json` (48 штук, формат «группа → список строк», `{name}`; id комплимента = группа + текст). Дмитрий дописывает тексты без правки кода; тест проверяет длину ≤ 70 и уникальность.
- БД: схема v2, таблица `easter_egg_log` (локальная, без синхронизации), миграция `from1To2`; тест миграции заменён на сгенерированный `make-migrations` (с проверкой данных).
- UI: `ComplimentBannerCubit` (5 секунд, смахивание вверх), `ComplimentOverlay` над навигатором в `AppTheme.builder`; вибрация `lightImpact`. События `ProjectCompleted`, `RowsCompleted`, `SecretTapped` должны слать T05–T09 через `getIt<AppEvents>()`.
- Зависимость dev: `fake_async`.
