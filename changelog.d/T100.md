## Для пользовательницы

- Вышивки на 200–250 цветов считаются заметно быстрее (на большом примере 70 с → 38 с), схема получается та же.

## Для разработки

- `suggestBlends`: кандидаты пар лежат в типизированных буферах, жадный отбор пересчитывает только пары, чья верхняя граница итога не ниже лучшего найденного; результат совпадает с прямым перебором (тест `blend_suggester_reference_test`).
- `AccentPaletteBuilder._reseed`: после первого круга ближайший цвет клеток уточняется только заменёнными цветами, «худшая клетка» ищется среди клеток с ошибкой выше порога; горячие проходы вынесены в отдельные функции (Dart JIT иначе не оптимизирует их в одной большой).
