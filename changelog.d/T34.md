## Для пользовательницы
- В мастере «Схема из картинки» появился переключатель «Только из моего запаса»: схема собирается только из мулине (любых брендов) или бисера, которые есть в «Моём запасе». Если подходящих цветов в запасе нет, мастер объясняет это и схему не рисует.

## Для разработки
- `ImageToGridSettings.onlyStash` (в рецепте `stash`, у старых рецептов `false`), `catalogFor(…, stash:)`; `ImageWizardCubit` читает запасы один раз в `start()`, `ImageWizardState.stashEmpty` останавливает расчёт при пустом отборе.
- Запас бисера не различает размеры: один код — одна запись.
