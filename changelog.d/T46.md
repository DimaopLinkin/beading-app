## Для пользовательницы

- В мастере «Схема из картинки» появился выбор «Вышивка». По фото получается схема для вышивки крестиком: нитки мулине DMC, а не бисер.
- Размер задаётся в сантиметрах на выбранной канве (Аида, равномерка, лён): число крестиков считается само, а под предпросмотром написано, сколько клеток и сантиметров получится. Поменяли канву, и размер в сантиметрах остался тем же.
- Цвет канвы (белая, молочная, под лён, серая, чёрная) становится фоном схемы. Если выбрать «Фон: Убрать», фон не вышивается, там остаётся канва.
- Контуры: тёмная линия бэкстичем по краям предмета и по резким границам, чтобы форма читалась чётче. Включены по умолчанию, выключаются одним касанием. Контуры сохраняются вместе со схемой.
- Бленды из двух ниток: если часть фото лучше передаётся двумя нитками в одной игле, мастер предложит это, и после включения заменит ими одиночные цвета.
- Для вышивки ширина и число цветов по умолчанию больше, чем для бисера (около 150 крестиков и 30 цветов): вышивка обычно крупнее.

## Для разработки

- `ImageToGridSettings`: `fabric`, `backstitch`, `blends`, `craft`, `metrics` (бусина или `Fabric`), `widthCm`, `techniquesOf(craft)`, `maxColumnsOf(craft)` (250 для вышивки). `catalogFor` и `toRequest` по ремеслу выбирают каталог бисера или мулине. Обводка бусиной только у бисера, контуры и бленды только у вышивки.
- `ImageToGridRequest.backstitch` и `applyBlends`; `GeneratedPattern.lines` (контуры T49: `OutlineBackstitch` после последнего шага, цвет — самый тёмный из палитры, в черновике не считаются; стадия `backstitch` в `stageTimes`).
- `applyBlends` (`blend_applier.dart`): предложения T57 становятся записями палитры с `PaletteEntry.blendPartner`; пустые нитки убираются. `paletteFromGenerated` собирает из них `PatternColor.blend`.
- `CreateGridPattern(layers:)`; `CreatePatternFromImage` теперь создаёт проект нужного ремесла и для вышивки пишет `StitchLayers` (линии контуров, сложения по канве).
- `ImageWizardCubit`: `setCraft`, `setFabric`, `setFabricColor`, `setWidthCm`, `setBackstitch`, `setBlends`; каталог мулине и бренд по умолчанию подгружаются в `start`.
- `GridViewOptions.canvasColor` закрашивает пустые клетки и фон вида «как будет выглядеть». Линии контуров в предпросмотре пока не рисуются (отрисовка слоёв вышивки — T39), число стежков показано текстом.
- Миграций БД нет.
