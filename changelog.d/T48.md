## Для пользовательницы

- Схема из фото теперь замечает лица и главный предмет: глаза, губы и контур предмета получают больше цветов и деталей, а фон — меньше.
- В мастере «Схема из картинки» появился переключатель «Выделять главное» (он виден, если на фото что-то нашлось). Всё считается на самом телефоне или компьютере, без интернета.

## Для разработки

- Домен: интерфейс `ImageMasks` (`analyze(png, width, height)`) и `ImageMaskSet` (маски объекта, человека и значимости `Uint8List`, лица с рамкой и ориентирами `DetectedFace`/`FaceLandmarks` в долях картинки). `importance()` складывает всё в одну маску (лицо ×4, объект ×2, фон ×0,5; без лиц и объекта — по значимости), `featureMask()` отдаёт пиксели черт лица для T54.
- Data: `MethodChannelImageMasks` (канал `app.beading/image_masks`; при любой ошибке `Err`, мастер идёт без масок).
- Платформа: `native/darwin/ImageMasksChannel.swift` — один файл для iOS и macOS (Vision: `VNGenerateForegroundInstanceMaskRequest`, `VNGeneratePersonSegmentationRequest`, `VNDetectFaceLandmarksRequest`, `VNGenerateAttentionBasedSaliencyImageRequest`), подключён в оба проекта Xcode.
- Мастер: `ImageWizardCubit` получает `ImageMasks`, кладёт маски в `ImageWizardState.masks` и маску важности в запрос; `ImageToGridSettings.useMasks`. Миграций БД нет.
- Кисть «важное» в мастере не входит в этот PR (вынесена в T60).
