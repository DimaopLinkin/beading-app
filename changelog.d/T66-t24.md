## Для пользовательницы

- В мастере у выбора детальности появился вариант «Как на фото»: простой перенос фото в клетки без сглаживания, больше деталей и одиночных клеток (по просьбе Дмитрия, для тех, кому нужна большая детализация).
- Размер схемы и число цветов теперь сразу берутся из подсказки по фото, пока вы сами их не меняли; подсказку можно применить заново одним касанием.

## Для разработки

- `ImageWizardCubit.setPreset(null)` снимает предустановку; подсказка T61 применяется сама до первой ручной правки размера (`_sizeTouched`). Миграций нет.
