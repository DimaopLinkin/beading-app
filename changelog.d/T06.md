## Для пользовательницы

- Теперь можно завести работу по схеме из книги: сфотографировать страницу или выбрать готовые фото и PDF. Из PDF можно взять несколько страниц сразу.
- Перед сохранением страницы можно повернуть, обрезать, поменять местами или убрать лишние.
- Схема хранится в приложении: копия работы забирает свои страницы, а при удалении работы они удаляются.

## Для разработки

- **Миграция БД v3 → v4** (`schemaVersion` = 4): таблицы `image_patterns` (одна на проект) и `image_pattern_pages` (упорядоченные страницы, относительный путь к PNG). Дамп `drift_schema_v4.json`, тест миграции с данными.
- Домен `lib/domain/image_pattern`: `ImagePattern`, `ImagePatternPage`, `CropRect`, интерфейсы `FileStore`, `ImageProcessor`, `PdfRasterizer`, `ImagePatternRepository`, `BookImageSource`; use case `ImportBookPattern` (проект `contentKind=image`, откат файлов и проекта при сбое), `ImagePatternContentCloner` и `ImagePatternContentCleaner`.
- Новый интерфейс `ProjectContentCleaner`; `DeleteProject` принимает `cleaners` и вызывает их после мягкого удаления. `CreateProject` принимает `coverPath`, у `Project` есть `withCoverPath`. Обе стороны подключены в DI вместе с `ProjectContentCloner` для `DuplicateProject`.
- Данные: `LocalFileStore` (Application Support, пути только относительные), `UiImageProcessor` (dart:ui: поворот, обрезка, PNG, потолок 4096 px; HEIC — средствами системы на iOS/macOS), `PdfrxPdfRasterizer` (pdfrx, 2×), `PickerBookImageSource` (image_picker, file_picker).
- Новые зависимости: `image_picker`, `file_picker`, `pdfrx`. iOS Info.plist: `NSCameraUsageDescription`, `NSPhotoLibraryUsageDescription`. macOS: entitlement `com.apple.security.files.user-selected.read-only`.
- Экран `/import/book` (`ImportBookCubit`, `ImportBookScreen`, `CropEditor`). Временная кнопка «+» в библиотеке: T05 заменит её пунктом реестра «Новый проект».
- Тест растеризации PDF берёт `libpdfium` из `.dart_tool/hooks_runner` (его скачивает хук пакета `pdfium_dart`); если библиотеки нет, тесты пропускаются.
