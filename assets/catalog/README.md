# Каталоги цветов

Файлы `*.json` в этой папке читает `CatalogSeeder` при запуске приложения. Формат:

```json
{
  "version": 1,
  "material": "bead",
  "brand": "Miyuki",
  "series": "Delica",
  "sizeCode": "11/0",
  "colors": [{ "code": "DB0306", "name": "Matte Dark Grey", "rgb": "#5a5a5c", "finish": "matte" }]
}
```

- `version` растёт при любой правке содержимого файла, иначе база не перечитает его.
- `material`: `bead` (бисер) или `floss` (мулине). У бисера обязателен `sizeCode`, у мулине его нет. У мулине обязательно поле `source` — происхождение данных (проверяет тест).
- Файлы других размеров (15/0, 8/0, Delica 10/0 и 15/0, T50; тот же скрипт и тот же источник) добавляются без изменения схемы: новый файл, `sizeCode` внутри.
- Фото производителей в каталог не кладём — только артикул, название, приблизительный RGB и отделка.

## Источники и честные оговорки

**Delica 11/0 (1 398 цветов, из них 128 сняты с производства) и Toho Round 11/0 (929 цветов)** собираются скриптом `tool/build_full_catalog.py` из пакета [adamaszczos/beadloo-assets](https://github.com/adamaszczos/beadloo-assets) (лицензия MIT, коммит записан в поле `source` каждого файла). Выбор и сравнение вариантов — в [ADR-0005](../../docs/decisions/0005-full-bead-catalog.md).

- **Артикулы, группа цвета, тип стекла, отделка, статус «снят с производства»** пакет берёт из официальных данных (для Miyuki — directory.miyuki-beads.co.jp и официальная таблица стойкости; для Toho источник пакета — страницы каталога, мы его отдельно не проверяли). Серия Delica Cut (`DBC…`) входит в файл Delica.
- **RGB измерен, а не угадан:** по 48×48-фото бусин из пакета тем же приёмом, что в самом пакете (центр кадра, OKLab, усечённое среднее по светлоте без бликов и щелей между бусинами). Скрипт повторяет `estimateBodyColor` из пакета. Точность не проверялась на колориметре: сверка по фото выборочная. Для 59 Delica, у которых вместо фото россыпи только образец со страницы каталога (`swatch` в реестре пакета), и для сильно переливающихся (Rainbow, AB, Galvanized) — заметно грубее: на экране цвет зависит от света и фото.
- **Названия:** торговых названий в источнике нет. У Delica название — признаки из официальных данных («Gray, Opaque, Metallic»), у Toho в группе цвета стоит само название («Lt Topaz»). Поиск по артикулу работает как раньше. Названия стартового набора T13 не перенесены: сверка с фото показала, что часть пар «артикул — название» там не совпадала с настоящей бусиной (например, Toho 612 — светло-серый матовый, а не Gun Metal).
- **`discontinued: true`** у цвета — снят с производства; приложение пока этот признак не использует.
- **`finish`** — одно значение из белого списка в `bundled_catalog_test.dart`, выбранное по приоритету: металлик, гальваника, серебро/золото внутри, окрашенный внутри, матовый, радужный, Ceylon, люстр, иначе прозрачный/непрозрачный.
- **Фото производителей в каталог не кладём** — только артикул, название, RGB и отделка; в пакете фото уменьшены, мы их не копируем.
- **Не заполнены:** `miyuki_rocailles_11.json` и `preciosa_rocailles_11.json` (в пакете они есть, но стоят в задаче T50 вместе с другими размерами: 15/0, 8/0, Delica 10/0).
- Размеры и вес бусин (`BeadSize`) сверены с таблицами розничных каталогов: диаметр Delica 15/0 1,3 мм, 11/0 1,6 мм, 10/0 2,2 мм, 8/0 3,0 мм; рокайль 15/0 1,3–1,5 мм, 11/0 2,1 мм, 8/0 3,1 мм; бусин в грамме: Delica 350 / 200 / 108 / 30, рокайль 250 / 110 / 39 (15/0, 11/0, 8/0).

## Мулине (T36)

**DMC Mouliné Spécial, арт. 117 (489 цветов)** собирается скриптом `tool/build_floss_catalog.py` из npm-пакета [craft-color-codes](https://www.npmjs.com/package/craft-color-codes) 1.0.0 (данные CC BY 4.0, MakeBead; атрибуция: «Color data: craft-color-codes by MakeBead, https://makebead.com»). Статус набора у автора — `cross-checked`: сверены три независимых источника (floss.maxxmint.com, adrianj/CrossStitchCreator — набор за R-пакетом `dmc`, xstitchify.com), спорные значения решены письменным правилом. Названия — английские официальные. Фото не берём.

- RGB — цвет для экрана, не колориметрическая мера: у реальной нитки он зависит от партии и света.
- **Anchor, Madeira, «Гамма», ПНК им. Кирова пока не добавлены.** Открытого источника RGB с понятным происхождением и лицензией для них не нашлось, а правило проекта — бренд без записанного происхождения не добавлять. Формат уже готов: новый файл `anchor_floss.json` с `"material": "floss"` и полем `source`, плюс строка в `lib/domain/settings/floss_brands.dart`. Пока замена в другой бренд («пересчитать палитру», `RecolorPalette`) работает на тех брендах мулине, что есть в каталоге.
