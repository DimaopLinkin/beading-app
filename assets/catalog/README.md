# Каталоги цветов

Файлы `*.json` в этой папке читает `CatalogSeeder` при запуске приложения. Формат:

```json
{
  "version": 1,
  "material": "bead",
  "brand": "Miyuki",
  "series": "Delica",
  "sizeCode": "11/0",
  "colors": [{ "code": "DB0306", "name": "Matte Dark Grey", "rgb": "#5a5a5c", "finish": "matte" }]
}
```

- `version` растёт при любой правке содержимого файла, иначе база не перечитает его.
- `material`: `bead` (бисер) или `floss` (мулине, добавит T36). У бисера обязателен `sizeCode`.
- Файлы других размеров (15/0, 8/0, Delica 10/0 и 15/0, T50) добавляются без изменения схемы: новый файл, `sizeCode` внутри.
- Фото производителей в каталог не кладём — только артикул, название, приблизительный RGB и отделка.

## Источники и честные оговорки

**Это стартовый набор, а не полные каталоги.**

- **Артикулы и названия** переписаны из публичных страниц розничных магазинов (Beadaholique, Land of Odds, Eureka Crystal Beads) на 2026-11-09: Miyuki Delica 11/0 — 42 позиции, Toho Round 11/0 — 34 позиции. Между магазинами они **не сверялись**, каждая пара «артикул — название» взята из одного источника; официальный каталог производителя не использовался. Набор случайный (то, что попало в выдачу), базовых артикулов вроде DB0010 в нём нет. Перед тем как обещать пользовательнице полноту, нужна сверка с официальными образцами.
- **RGB** — приблизительный цвет для экрана. Производители не публикуют машиночитаемых значений, поэтому цвета подобраны по названию и виду, а не измерены. Для подбора «ближайшего по ΔE» этого достаточно, для точной печати нет.
- **Не заполнены:** `miyuki_rocailles_11.json` и `preciosa_rocailles_11.json` (проверенных артикулов в доступных источниках нет; официальные образцы Preciosa — PDF «Rocailles Sample Cards» с картинками). Полные списки Delica (≈1 500 цветов), Toho и Miyuki нужно загружать из источника, который подтвердит Дмитрий, отдельным шагом (T50).
- Размеры и вес бусин (`BeadSize`) сверены с таблицами розничных каталогов: диаметр Delica 15/0 1,3 мм, 11/0 1,6 мм, 10/0 2,2 мм, 8/0 3,0 мм; рокайль 15/0 1,3–1,5 мм, 11/0 2,1 мм, 8/0 3,1 мм; бусин в грамме: Delica 350 / 200 / 108 / 30, рокайль 250 / 110 / 39 (15/0, 11/0, 8/0).
