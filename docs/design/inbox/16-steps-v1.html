Канитель · Пошаговые инструкции · 16-steps v1

Решения и оговорки

  • Один экран для всех маршрутных техник. Главный экран «инструкция в работе» (B) похож по духу на плетение: крупная зона шага сверху, управление внизу в зоне большого пальца. Стекло только у верхней панели и нижней панели кнопок; фото и текст шага непрозрачные. Кнопки внутри стеклянной нижней панели залиты (акцент / нейтральная заливка), поэтому «стекло на стекле» нет.
  • Прогресс — одна позиция «я здесь». Всё до текущего шага отмечено галочкой; в списке шагов текущий выделен кольцом с точкой и подсветкой строки (не только цветом). В панели: «Секция 2 из 3 · Ёлочка» и тонкая линия общего прогресса; над текстом: «Шаг 12 из 21». Внутри секции с повтором: «повтор 4 из 10» + 10 сегментов (пройдено, текущий, впереди). Для повтора «до нужной длины»: «4-й повтор» без общего числа и кнопка «Достаточно» (после неё идём дальше).
  • Нумерация шагов. «Шаг 12 из 21» считает шаги, как их написала мастерица, а не развёрнутые повторы: секция «Ёлочка» (шаги 8–16) повторяется 10 раз, но шагов в ней по-прежнему 9. Прогресс показывает и номер шага, и номер повтора.
  • Бусины. Чип «3 × A»: кружок цвета бусины из палитры работы + число + буква палитры; цвет бусины не меняется темой (кружок ровный, с тонкой тёмной обводкой для светлых цветов, например «Жемчуг»). Буквы нужны, чтобы различать похожие цвета, а не только цветом.
  • Фото шага во всю ширину, непрозрачное, щипок и двойное касание увеличивают (показано подсказкой на первом экране). Несколько фото — системный page control + счётчик «2 из 3» (свайп влево/вправо по фото). Фото на макете условные: нарисованные заглушки, не фотографии. Заглушка «Фото не загрузилось» с кнопкой «Повторить» (B9).
  • Размер текста шага: два размера показаны (обычный 20 pt, крупный 28 pt, B3); регулируется системным размером текста или в настройках (кнопка «Aa» в верхней панели в макет не вынесена, чтобы не перегружать панель). Свайп по тексту — назад/вперёд; кнопки дублируют свайп. Экран не гаснет (в макете ничего не нарисовано, это поведение).
  • Нижняя панель. «Назад» (нейтральная) и «Готово, дальше» (акцент, 64 pt), зазор 8 pt, подписи 18–20 pt. Для последнего шага панель в два ряда: «Готово: отметить работу законченной» и под ней «Назад», потому что длинная подпись в один ряд не помещается без уменьшения шрифта.
  • Список шагов (B10) — системный page sheet (large), группы по секциям, свёрнутые секции с disclosure-стрелкой (пройденная секция показывает «7 из 7»), касание строки переходит к шагу. На Mac список — боковая колонка слева (B11), в узком окне 520 pt она скрывается за кнопкой «список» на панели окна (B12).
  • Редактор (C). Автосохранение без кнопки «Сохранить»: ненавязчивая строка «Сохранено» с галочкой под названием; при ошибке — «Не сохранено: проверьте повтор». Секции и шаги переставляются перетаскиванием за рукоятку справа в режиме «Изменить» (C2); у секции — «Повтор N раз» (системное меню/степпер), «…» с меню (переименовать, дублировать, удалить). Удаление шага без диалога: баннер «Шаг удалён · Отменить» (C9). Ошибка «повтор 0» показана рамкой, иконкой и текстом (не только цветом) (C6).
  • Фото в редакторе: плитки 96 pt с порядковым номером и крестиком (зона нажатия 44 pt), «Добавить» открывает системное меню «Снять фото / Выбрать из галереи» (C5); порядок меняется перетаскиванием.
  • Бусины в шаге выбираются из каталога/палитры работы, как в редакторе схем: строка «A · Рубин» + количество (степпер) и «Добавить бусины из каталога». Повтор шага: системный сегмент «Один раз / N раз / До нужной длины» + число.
  • Карточка в библиотеке (D): превью = фото текущего шага (или первое), подпись «Шаг 12 из 21 · секция 2»; показана и в списке, и в сетке 2 колонки рядом со схемами. Статус «В работе» тем же значком, что у схем.
  • Тон текстов: «Готово, дальше», «Назад», «Достаточно», «Работа закончена»; без смайлов, без «поделиться / оценить / зарегистрироваться».
  • Нестандартное: степпер 44 pt (системный UIStepper 32 pt мелковат для мокрых пальцев), сегменты повторов (10 штук; это индикатор, не контрол), чипы бусин, нижняя панель из двух кнопок на стекле, плитки фото. Остальное системное: page sheet, сегменты, формы-группы, меню, баннер, page control, disclosure.
  • Оговорки: AX3 не рисовался (крупный текст шага показан двумя размерами, остальное интерфейс 17 pt); шаблоны (Крестик/RAW, Ёлочка, Сетка, Жгут) условные; иллюстрации и фото шагов — схематичные заглушки; SF Symbols (list.bullet, repeat, photo, camera, trash, line.3.horizontal) нарисованы приближённо.
