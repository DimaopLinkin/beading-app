Решения и оговорки

  • Данные настоящие. Образцы, артикулы, названия и RGB взяты из стартового набора приложения (assets/catalog: Miyuki Delica 11/0, 42 цвета, и Toho Round 11/0, 34 цвета), а не придуманы. README каталога честно оговаривает: набор неполный, RGB приблизительный, артикулы между магазинами не сверены. Поэтому в листе «Похожие» стоит строка «Цвета в каталоге приблизительные», а вкладка Miyuki Rocailles показана пустой («каталог пока не загружен»), потому что файла с данными нет.
  • Мера похожести — ΔE (CIE76 в Lab), считается на этой странице по RGB из каталога. Метки: до 2 «почти неотличим», до 5 «очень близко», до 10 «близко», дальше «похож». Полоска — отдельный индикатор: длина = 1 − ΔE/30. Ищется среди всех каталогов, не только текущего (рядом указан производитель).
  • Режим «Подобрать похожий»: кнопка в верхней панели; в режиме тап по образцу не открывает карточку, а выбирает цвет (двойное кольцо из 01b), результат — нижний лист с пятью ближайшими.
  • Верхняя панель каталога стеклянная целиком (заголовок, вкладки производителей, поиск), кнопки и поля внутри плоские. Сетка, образцы, таблица материалов и лист «Поделиться» (содержимое) непрозрачные, цвета бусин не тонируются; блик на образце это декоративный белый блик 35% только на круге-образце.
  • Материалы: количество бусин по схеме, вес ≈ = количество / бусин в грамме. Для Delica 11/0 это 200 бусин/г (по таблице из README каталога), для Toho Round 11/0 в README данных нет, я принял оценку по рокайлю 11/0, 110 бусин/г, и помечаю это в макете как оценку. Реальные значения нужно заменить на данные `BeadSize` из приложения.
  • Текст ≥ 13 pt, зоны нажатия ≥ 44 pt, Dynamic Type и Mac в этом промпте не показаны; цвета бусин в строках различаются символом-буквой, а не только цветом.
