# 18-generator-editor v1: мастер «Схема из картинки» как редактор

Файл макета: `18-generator-editor-v1.html` (светлая / тёмная / обе рядом, 19 экранов iPhone 428 × 926 и 3 окна Mac).

## Идея
Результат занимает основную часть экрана, все параметры лежат в нижней панели. Внизу полоса инструментов (SF Symbol + подпись 13 pt): Основа, Размер, Цвета, Детали, Стежки, Итог (у бисера пять, без «Стежков»). Выбранный инструмент открывает над полосой панель с 1–4 элементами. Повторное нажатие на выбранный инструмент сворачивает панель.

## Что где
| Экран | Кадры |
|---|---|
| 1. Первый расчёт, «Размер» | 1 |
| 2. «Цвета» в движении, строка брендов, лист мультивыбора | 2, 2б |
| 3. «Основа», «Размер» (высота), «Детали», «Стежки», «Итог» с готовой схемой | 3а–3д |
| 4. Панель свёрнута, схема увеличена щипком | 4 |
| 5. Удержание: исходное фото | 5 |
| 6. Баннер про лицо с действием | 6 |
| 7. Бисер (станок): «Основа», «Цвета» (серия, отделки) | 7а, 7б |
| 8. Сохранение: системный алерт с полем | 8 |
| 9. Варианты высоты панели: A «как в Фото» (развёрнута, свёрнута), B «как в Картах» (свёрнут, средний, большой) | 9а–9д |
| Mac: окно 1000 pt (Размер, Цвета), узкое 640 pt | M1–M3 |

## Где нет системного компонента (сделано самостоятельно)
- **Колесо-шкала** (ширина, высота, число цветов): значение крупно, «−» и «+» по краям (44 pt), шкала с делениями и акцентной меткой по центру. Нажатие на значение вводит число. В UIKit такого нет, ориентир: «Коррекция» в «Фото».
- **Полоса инструментов** с иконкой и подписью и **точка изменения** на иконке (изменено против умолчаний).
- **Панель** в варианте A (в системе есть аналог только в «Фото»).
- Круглые образцы цвета канвы (30 pt, зазор 10 pt; зону нажатия сделать 44 pt за счёт отступов).
- Стеклянная плашка размера и сегмент «Схема / Как будет» поверх результата.

Системные: сегменты, переключатели, pull-down строки («Канва», «Мулине», «Серия»), лист мультивыбора брендов (page sheet), алерт с полем, кнопки «Отмена» / «Сохранить».

## Решения дизайнера
- Нет в задании, добавлено: в «Размере» сегмент «Ширина / Высота» выбирает, какое число крутит колесо; подсказка по фото («Применить 60 × 101 см») вынесена в первый чип ряда, чтобы колесо и ряд действий помещались в панель без прокрутки.
- В «Цветах» строка «Нитки других производителей» стоит сразу под сегментом палитры (раньше «Только из моего запаса»), чтобы строка со сводкой «Авто» была видна в панели без прокрутки.
- Точка изменения подкреплена подсветкой самого значения (цвет акцента) в панели; сама по себе она не единственный носитель смысла.
- A vs B: в A результат больше при любом инструменте и панель не перекрывает его; в B в большом фиксаторе видна вся группа целиком (удобно для «Размера»), но результат сжимается до узкой полосы. Выбор за Дмитрием.
- Mac: вкладки инструментов сегментами из иконок (подпись выбранной — заголовок инспектора), группа «Размер» целиком без прокрутки; узкое окно (640 pt) работает как iPhone.
