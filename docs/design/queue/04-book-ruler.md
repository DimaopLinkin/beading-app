# Схема из книги: работа с линейкой (MUST-B2–B4)

Используй UI kit из предыдущего шага (`docs/design/accepted/01-ui-kit/ (Main/Components/Icon.dc.html) и docs/design/queue/01b-ui-kit-addendum.md`, Liquid Glass для слоя управления, контент непрозрачный).

Экран плетения по фото страницы из книги. Изображение занимает почти весь экран, зум щипком и панорама. Поверх — горизонтальная полупрозрачная «линейка», выделяющая текущий ряд; всё выше неё слегка притушено. Внизу крупная панель: «Ряд 17», кнопки «▲ назад» и «▼ следующий ряд» (большие, под большой палец), иконка настройки линейки (высота, шаг сдвига, цвет подсветки) и иконка заметок. Заметки открываются нижним листом. Покажи: обычный вид, приближенный вид, настройку линейки, заметки. Обе темы.
