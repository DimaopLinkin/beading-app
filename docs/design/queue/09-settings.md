# Настройки и «О приложении»

Используй UI kit из предыдущего шага (`docs/design/accepted/01-ui-kit/ (Main/Components/Icon.dc.html) и docs/design/accepted/01b-ui-kit-addendum/`, Liquid Glass для слоя управления, контент непрозрачный).

Настройки: тема (системная/светлая/тёмная), «Не гасить экран», режим символов по умолчанию, производитель бисера по умолчанию, резервная копия (экспорт/импорт файла), синхронизация с iCloud (вкл/выкл, статус). «О приложении»: логотип, версия, короткая тёплая подпись. Обе темы.
