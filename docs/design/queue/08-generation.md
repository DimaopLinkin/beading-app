# Генерация (MUST-E1–E2)

Используй UI kit из предыдущего шага (`docs/design/accepted/01-ui-kit/ (Main/Components/Icon.dc.html) и docs/design/accepted/01b-ui-kit-addendum/`, Liquid Glass для слоя управления, контент непрозрачный).

Два мастера. (1) «Схема из картинки»: выбор фото → обрезка → параметры (техника, ширина в бусинах, число цветов, «только цвета каталога» / «только мои запасы», сглаживание) → живой предпросмотр «до/после» → сохранить. (2) «Узор по шаблону»: галерея шаблонов (полосы, зигзаг, ромбы, шахматка, градиент), параметры шаблона (ширина, высота, период, цвета) с живым предпросмотром браслета. Обе темы.
