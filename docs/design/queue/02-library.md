# Библиотека проектов

Используй UI kit из предыдущего шага (`docs/design/accepted/ui-kit.html`, Liquid Glass для слоя управления, контент непрозрачный).

Экран «Мои работы» — главный. Сверху заголовок и поиск, под ним чипы фильтров: техника (станок, мозаика, кирпич, другое) и статус (идея, в работе, готово). Список карточек проектов, отсортированных по дате последней работы; у «в работе» видна мини-полоса прогресса. Свайп по карточке — переименовать, дублировать, удалить (удаление с подтверждением). Плавающая кнопка «+» открывает лист «Новый проект» с вариантами: «Схема из книги (фото или PDF)», «Нарисовать схему», «Схема из картинки», «Узор по шаблону». Покажи: заполненный список, пустое состояние, результат поиска без совпадений. Обе темы.
