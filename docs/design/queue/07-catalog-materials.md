# Каталог цветов и материалы (MUST-D1–D4)

Используй UI kit из предыдущего шага (`docs/design/accepted/ui-kit.html`, Liquid Glass для слоя управления, контент непрозрачный).

Два экрана. (1) Каталог: вкладки производителей (Miyuki Delica, Miyuki Rocailles, Toho), поиск по артикулу и названию, сетка образцов; режим «подобрать похожий» — выбрать цвет и увидеть 5 ближайших с мерой похожести. (2) Материалы проекта: таблица цветов схемы — образец, символ, артикул, название, количество бусин, примерный вес в граммах, итог. Кнопка «Поделиться списком». Обе темы.
