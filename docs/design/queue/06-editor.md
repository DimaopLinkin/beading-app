# Редактор сеточной схемы (MUST-C1–C6)

Используй UI kit из предыдущего шага (`docs/design/accepted/01-ui-kit/ (Main/Components/Icon.dc.html) и docs/design/accepted/01b-ui-kit-addendum/`, Liquid Glass для слоя управления, контент непрозрачный).

Редактор схемы. Шаг 1 — лист создания: техника (станок/квадратный стежок, мозаика, кирпич), ширина и высота в бусинах, размер бисера, предпросмотр будущих размеров в сантиметрах. Шаг 2 — редактор: схема на весь экран с зумом, снизу панель инструментов (кисть, ластик, заливка, пипетка, заменить цвет, выделение, зеркало по горизонтали/вертикали, вставить/удалить ряд или столбец, отменить/повторить), над ней лента палитры схемы с текущим цветом. Нажатие на цвет в палитре — лист редактирования: название, цвет, выбор из каталога с поиском по артикулу. Покажи iPhone и широкое окно macOS (палитра сбоку). Обе темы.
