# Лист «Новый проект» с выбором ремесла и фильтры библиотеки

Используй принятое: `docs/design/accepted/02-library/index.html`, UI kit (`docs/design/accepted/01-ui-kit/`, `docs/design/accepted/01b-ui-kit-addendum/`). Меняй только описанное ниже.

Контекст: в приложении два ремесла, бисер и вышивка крестом. В принятом листе «Новый проект» (экран 3 в 02-library) выбора ремесла нет, а в реализации он нужен, потому что способы создания у ремёсел разные (у вышивки: схема из фото, редактор крестиков; у бисера: книга, редактор, картинка, шаблон).

Нарисуй: (1) лист «Новый проект» с выбором ремесла вверху (сегмент «Бисер / Вышивка» нативного вида) и списком способов под ним в стиле принятого листа (круглая плитка с иконкой, название, подпись, кнопка «Отмена»); покажи оба ремесла; (2) строку фильтров библиотеки с ремеслом: чипы «Бисер», «Вышивка» плюс статусы «Идея», «В работе», «Готово», два ряда, без обрезания на 428 pt и при Dynamic Type AX3; (3) пустое состояние библиотеки как в принятом макете. Обе темы. Фон листа и чипов в тёмной теме заметно светлее фона экрана, как поверхность kit 01.
