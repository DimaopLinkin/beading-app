# Плетение пейота по столбцам (доработка 05-weaving)

Используй принятый экран `docs/design/accepted/05-weaving/index.html` и UI kit (`docs/design/accepted/01-ui-kit/`, `docs/design/accepted/01b-ui-kit-addendum/`). Меняй только то, что связано с пейотом, остальное оставь как в принятом.

Контекст: в реализации (T19) прогресс пейота ведётся не по рядам, а по столбцам (в схеме, повёрнутой так, что бисер идёт вертикальными парами). Станок остаётся по рядам. В принятом макете пейот нарисован горизонтальным зигзагом по рядам, это нужно привести в соответствие.

Покажи: (1) шапку пейота: «Столбец 7 из 16» тем же крупным счётчиком 40 pt (AX3 54 pt) и шапку станка «Ряд 42 из 180» рядом для сравнения; (2) подсветку текущего столбца (двойной контур вокруг бусин столбца, пройденные притушены, как в 01b), по бусине и по столбцу; (3) word chart столбца со стрелкой направления (вверх/вниз); (4) режим символов; (5) завершение проекта для пейота. Обе темы. Не меняй принятое для станка.
