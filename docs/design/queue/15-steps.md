# Пошаговые инструкции для маршрутных техник

Используй UI kit из `docs/design/accepted/01-ui-kit/` и `01b-ui-kit-addendum/` (Liquid Glass только для слоя управления, контент непрозрачный). Экран работы с инструкцией по духу близок к экрану плетения (`05-weaving`): телефон лежит на столе, руки в бисере, нужны крупные кнопки внизу и высокий контраст.

## Что это

Для техник без сетки (крестик/RAW, ёлочка, сетка, жгуты, цветы, спирали) схемы нет, есть последовательность шагов: текст, фото или рисунок этапа, какие бусины брать («3 × A»), сколько раз повторить. Это только бисер, вышивка не затрагивается. Шаги идут строго по порядку, прогресс — одна позиция «я здесь» (всё до неё сделано). Никаких кнопок «зарегистрироваться/поделиться/оценить», никаких смайлов и сюсюканья в текстах.

## Экраны и состояния (каждый в светлой и тёмной теме)

### A. Новая инструкция (лист «Новый проект → Пошаговая инструкция»)
- Системный лист. Две верхние строки: «Пустая», «Из фото» (по фото на шаг, из камеры или галереи).
- Ниже раздел «Шаблоны техник»: карточки (название, иллюстрация, сложность, число шагов): «Крестик (RAW)», «Ёлочка», «Сетка», «Жгут». Содержание условное, покажи 4 штуки.
- Просмотр шаблона перед созданием: прокручиваемый список шагов только для чтения, кнопка «Создать» внизу.
- Состояния: пусто (нет шаблонов), загрузка.

### B. Инструкция в работе (главный экран)
- Верх: название работы, стеклянная панель, «секция 2 из 3».
- Центр: фото шага во всю ширину (непрозрачное, зум щипком/двойным касанием), под ним крупный текст шага (размер текста можно менять, показать два размера), чипы бусин «3 × A» цветом бусины из палитры работы, счётчик повтора «повтор 4 из 10» (для «до нужной длины» — «4-й повтор» без числа, и кнопка «Достаточно»).
- Низ (зона большого пальца): большая кнопка «Готово, дальше», рядом «Назад». Свайп по тексту — назад/вперёд.
- Список шагов (лист снизу или боковая колонка на Mac): галочки до текущего, текущий выделен, касание — перейти.
- Состояния: первый шаг, середина с повтором, шаг без фото, шаг с несколькими фото (пейджер), последний шаг («Готово: отметить работу законченной»), работа закончена, фото не загрузилось (заглушка).
- Экран не гаснет. Mac: список шагов слева, шаг справа, окно 480–1000 pt.

### C. Редактор шагов (в основном Mac, но и на iPhone)
- Список секций со шагами, перетаскивание шагов и секций, добавить шаг/секцию, повтор секции («N раз»).
- Шаг: многострочный текст, фото (камера/галерея, порядок, удалить), бусины из палитры (выбор из каталога, как в редакторе схем), повтор «N раз» или «до нужной длины».
- Автосохранение, без кнопки «Сохранить»; состояние «сохранено» ненавязчивое.
- Состояния: пустая инструкция, длинная инструкция, шаг с ошибкой (повтор 0), удаление шага (отмена в баннере).

### D. Карточка в библиотеке «Мои работы»
Превью = фото текущего шага (или первое), подпись «Шаг 12 из 48 · секция 2». Покажи в сетке рядом с карточками схем.

## На что обратить внимание
- Тексты живые и спокойные: «Готово, дальше», «Назад», «Достаточно».
- Не придумывай нестандартные контролы там, где есть системный компонент iOS; оговори исключения в пояснении.
- Результат — по правилам `docs/design/CLAUDE_DESIGN.md`.
