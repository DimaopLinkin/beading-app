# Линейка: понятная ручка высоты ряда

Используй принятое: `docs/design/accepted/04-book-ruler/index.html`, UI kit (`docs/design/accepted/01-ui-kit/`, `docs/design/accepted/01b-ui-kit-addendum/`). Меняй только описанное.

Проблема (из реального использования): пользователь не понял, как менять высоту ряда на линейке. Ручка на нижней границе полосы, пилюля со стрелками без подписи, неочевидна.

Нарисуй: (1) явную ручку высоты: крупная (не меньше 44 pt зона нажатия), с подписью или иконкой, понятной без объяснений, расположенную так, чтобы палец её не закрывал; (2) подсказку при первом открытии линейки («Потяните за ручку, чтобы подогнать высоту ряда под книгу»), как она появляется и исчезает; (3) состояние при перетаскивании (подсказка с текущей высотой, лупа или увеличение фрагмента под пальцем); (4) то же при Dynamic Type AX3. Обе темы. Компоненты нативные по iOS design code, где системный есть (подсказка как popover/TipKit-подобная).
