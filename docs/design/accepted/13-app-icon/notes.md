# Иконка «Канитель», версия 1

Концепция: одна непрерывная металлическая нить. Слева на неё нанизана гранатовая стеклянная бусина, дальше нить закручивается в мягкий виток («канитель»), перекрещивает себя один раз и вливается в первый штрих одного крестика. Бисер и вышивка на равных: бусина слева, крестик справа, между ними сама нить. Иглы нет. Без сердечек и «милоты».

Обзор: `13-app-icon-v1/index.html` (все виды, слои, домашний экран iPhone в светлом, тёмном и tinted режимах, Dock на Mac, мелкие размеры 29 / 40 / 60 pt и 16 / 32 px, альтернативный вариант, таблица цветов).

## Файлы

```text
13-app-icon-v1/
  index.html                    страница-обзор
  png/ios-light.png             iOS светлая (Default), 1024 × 1024, без альфы, без маски
  png/ios-dark.png              iOS тёмная (Dark), 1024 × 1024, без альфы
  png/ios-tinted.png            iOS Tinted (Mono), 1024 × 1024, оттенки серого
  png/macos-light.png           macOS светлая, 1024 × 1024, прозрачные углы (тело 824 × 824, поля 100)
  png/macos-dark.png            macOS тёмная, то же
  layers/{light,dark,tinted}/   background.svg, thread.svg, bead.svg, cross.svg (холст 1024 × 1024, одинаковый)
  composite/                    все слои одним SVG для каждого вида (источник для PNG)
```

Слои для Icon Composer: порядок снизу вверх `background`, `thread`, `bead`, `cross`. Нить одним слоем (перекрест витка нарисован внутри слоя с тенью), поэтому его нельзя разделять. Для tinted достаточно слоёв светлого или тёмного набора (система окрашивает по яркости), серый набор `layers/tinted/` дан, чтобы форма читалась без цвета.

## Цвета (hex)

| Элемент | Светлая | Тёмная | Tinted |
|---|---|---|---|
| Фон (градиент по диагонали) | `#F1E8D6` → `#E4D7BE` (лён) | `#2A211B` → `#15100D` | `#1B1B1B` → `#0C0C0C` |
| Нить: блик / металл / тень / кромка | `#F3D9A2` / `#CC9847` / `#8F5C26` / `#6B4118` | `#F5D898` / `#D9A650` / `#9C6628` / `#5A3714` | `#FFFFFF` / `#E3E3E3` / `#A9A9A9` / `#5C5C5C` |
| Бусина: свет / основа / глубина | `#D8506F` / `#8E1E3A` / `#560C22` | `#D8607F` / `#A22745` / `#5E1129` | `#B8B8B8` / `#7A7A7A` / `#3A3A3A` |
| Крестик | цвета нити | цвета нити | цвета нити |

Бусина гранатовая, нить латунная (тёплый металл, не «казино-золото»), крестик того же металла. Бусина в tinted темнее нити, поэтому форма различима и без цвета. Фон: льняная канва с едва заметным переплетением (линии сетки 32 px, непрозрачность 5–11 %) и мягкой виньеткой.

## Что проверено и что нет

- Безопасная зона iOS: важные формы внутри центральных 80 % (102–922). Рисунок занимает примерно 120–890 по горизонтали и 250–780 по вертикали.
- Читаемость: на 58 px (29 pt @2x) различимы бусина, виток и крестик; на 32 px то же, но тоньше; на 16 px остаются силуэт нити и два акцента (бусина, крестик), блики и фон пропадают. Нить утолщена до 64 px именно ради мелких размеров.
- Не проверялось в настоящем Icon Composer и на устройстве: `.icon` не собирался, стекло и блики iOS 26 в обзоре имитируются. Скругление macOS задано скруглённым прямоугольником (радиус 185), а не «непрерывной» кривой Apple; для финала лучше брать форму из шаблона Apple.
- Альтернативный вариант (нить по ячейкам сетки) показан только в обзоре, слоёв и PNG для него нет. Основным оставлен завиток нити: он читается мельче.
