Решения и отступления

Порядок шагов для PDF (так показано): 1 источник, 2 выбор страницы, 3 обрезка, 4 название и техника. Для камеры и «Фото» шага выбора страницы нет, нумерация сжимается до «из 3», а подсказка про бликах («без бликов на глянцевой бумаге») остаётся на экране источника. Стекло только на плавающем слое: верхняя панель, нижняя панель с кнопкой. Миниатюры страниц, фото страницы, поля и плитки выбора непрозрачные; кнопки и инструменты внутри стеклянных панелей плоские. Видоискатель камеры всегда тёмный в обеих темах (это контент), стеклянные панели над ним используют тёмный вариант стекла для читаемости. Выбранная страница и выбранная ячейка в сетке помечены двойным кольцом из 01b и галочкой (не только цветом). Ручки обрезки визуально 28 pt, зона нажатия 44 pt. «Нет доступа к камере» показан отдельным состоянием: из него есть выход через «Фото» и «Файлы». В макете нет клавиатуры iOS: при вводе названия панель с кнопкой поднимается над ней. Макет Mac для импорта в этом промпте не делался.
