Бисер · Редактор сеточной схемы · 06-editor v1

Решения и оговорки

  • Лист создания и лист «Цвет» нарисованы как системные page sheet (как принятый 02b): системная ручка, «Отмена» слева в навигационной панели, «Создать» / «Готово» справа, нативные группы строк, сегменты и степперы. Лист создания открывается на large (в нём много полей). Самодельных панелей нет.
  • Лист создания: техника (три плитки со схемой укладки: станок / квадратный стежок, мозаика / пейот, кирпич), ширина и высота в бусинах (степперы 44 pt), размер бисера (сегмент 15/0, 11/0, 10/0, 8/0), предпросмотр: контур схемы в масштабе и размеры в сантиметрах. Сантиметры считаются на странице: диаметр бусины 1,3 / 1,6 / 2,2 / 3,0 мм (по таблице `BeadSize` из README каталога, Delica 15/0, 11/0, 10/0, 8/0); для мозаики высота +½ бусины, для кирпича ширина +½ бусины (сдвиг рядов). Это упрощение: фактическая высота бусины Delica немного меньше диаметра, точные размеры возьмёт реализация из `BeadSize`.
  • Редактор на iPhone: схема на весь экран (непрозрачная, с зумом; индикатор масштаба и «По размеру» разделены, как в 04), стеклянная верхняя панель (назад, название, отменить / повторить) и одна нижняя панель в два ряда: лента палитры схемы с текущим цветом (слева капсула с кружком и артикулом, справа прокручиваемые образцы; выбранный с двойным кольцом из 01b) и ряд инструментов: кисть, ластик, заливка, пипетка, замена цвета, выделение, зеркало, «ряды и столбцы». Зеркало и «ряды и столбцы» открывают нативное меню (UIMenu), потому что всё вместе в 428 pt не помещается: вставить / удалить ряд или столбец, зеркало по горизонтали и вертикали лежат в меню. Все кнопки 44 pt и больше, без подписей (иконки, названия в accessibility label); внутри стекла кнопки плоские.
  • Нажатие на цвет в палитре открывает лист «Цвет»: превью с символом, название (своё, по умолчанию из каталога), символ, строка «выбрано из каталога» и поиск по артикулу и названию с результатами из стартового каталога (`assets/catalog`, реальные данные). Названия в результатах переносятся (не обрезаются многоточием, как просило ревью 07).
  • Mac, окно 900 pt: боковая панель с палитрой (стекло), тулбар (стекло, инструменты, отменить / повторить, масштаб), холст и инспектор «Текущий цвет» непрозрачные. По замечанию ревью 01b инспектор не обрезается окном (у него своя колонка 196 pt, холст уже), и его можно свернуть (шеврон в заголовке): в свёрнутом виде холст получает всю ширину.
  • Выделение (экран 6): рамка с двойным контуром, угловые ручки, размер выделения в подсказке; на время выделения нижний ряд инструментов заменяется действиями с подписями 13 pt; «Зеркало» открывает то же системное меню (по горизонтали / по вертикали). Не рисовались: Dynamic Type AX3 (подписей у инструментов нет, текст в листах масштабируется как в 02b), Rocailles (каталог пуст, как в 07), клавиатура, жесты зума.
