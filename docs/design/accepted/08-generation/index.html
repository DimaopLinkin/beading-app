Бисер · Генерация: схема из картинки и узор по шаблону · 08-generation v1

Решения и оговорки

  • Предпросмотр «до/после» считается на самой странице. «До» процедурная картинка (закат над озером, не фотография), «после» её схема из бусин: картинка снимается по клеткам, цвета подбираются из стартового каталога Miyuki Delica (только непрозрачные и матовые, 362 цвета, как по умолчанию в задаче T62), ближайший по ΔE (CIE76 в Lab). Это иллюстрация, а не результат настоящего генератора (T24–T66): реальная схема будет отличаться (сглаживание, маска важности, дизеринг не показан).
  • Мастер «Схема из картинки»: шаг 1 выбор фото (системный выбор фото, как в 03), шаг 2 обрезка (рамка с ручками, пропорции), шаг 3 параметры с живым предпросмотром, шаг 4 сохранение. Параметры по промпту: техника, ширина в бусинах (с размером в сантиметрах и подсказкой назначения «браслет / панно / картина» из T61), число цветов, «Каталог / Мои запасы», сглаживание; сверху предустановка «Проще / Сбалансированно / Детально» (T66). Серия бисера (Delica или Toho) выбирается строкой «Серия» (T62).
  • Предпросмотр «до / после»: одна картинка с разделителем, который двигается пальцем (ручка 34 pt, зона нажатия 44 pt), подписи «До» и «После». При изменении параметра предпросмотр пересчитывается с задержкой около 0,3 с (дебаунс), прежний результат остаётся приглушённым, пока идёт расчёт, и показывается индикатор «Пересчитываю…» (экран 4); устаревший расчёт отменяется. Результат всегда рисуется в масштабе «по ширине».
  • Параметры лежат в нижнем листе без затемнения (non-modal page sheet с детентами, предпросмотр остаётся доступным над ним); внутри лист нативный: сегменты, группы строк, слайдеры, степперы. Стекло только у верхней панели и у самого листа (системный материал), кнопки внутри плоские.
  • «Мои запасы» (экран 5): запасы бисера в проекте «бонус» (таблица `inventory`), поэтому по умолчанию их может не быть. Тогда в листе вместо серии показано сообщение «Запасов пока нет, палитра будет взята из каталога» и ссылка «Открыть запасы». Если запасов не хватает на нужное число цветов, приложение предупредит так же.
  • AX3 (экран 6): параметры открываются на large (во весь экран), в верхней части листа остаётся компактная полоса «до/после»; подписи 26–30 pt, слайдеры с ручкой 44 pt, сегменты 68 pt; предустановка «Проще / Сбалансированно / Детально» в сегмент не помещается и становится строкой-меню.
  • Мастер «Узор по шаблону»: галерея из шести шаблонов (полосы, зигзаг, ромбы, шахматка, градиент по Lab и бордюр, последний есть в T22, хотя в промпте назван не был), параметры (ширина, высота, период, цвета), живой предпросмотр браслета с застёжками и фрагмент схемы крупнее, потому что на полосе 60 × 12 отдельные бусины не различить. Цвета шаблона выбираются из каталога (нажатие на цвет открывает лист выбора из каталога, как в 06). У градиента вместо периода «Ступеней», и показаны два конца; промежуточные цвета подбираются по каталогу.
  • Сантиметры: диаметр бусины Delica 11/0 1,6 мм (README каталога). Не рисовались: Mac, клавиатура, системный выбор фото, лист выбора цвета (как в 06). Цвет сцены и градиента не тонируются темой.
