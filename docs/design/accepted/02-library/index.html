Решения и отступления

Экран собран по принятому UI kit v1 с учётом дополнения 01b: текст не меньше 13 pt, статус «в работе» тёмно-янтарный #8A5300 (светлая) на заливке 16%, статусы различаются не только цветом, а иконкой (кольцо, полукруг, галочка). Стекло только у плавающего слоя: панель табов, кнопка «+», лист «Новый проект», диалог удаления. Заголовок, поиск, чипы и карточки непрозрачные. Кнопки свайпа плоские, не стекло. Поиск стоит под большим заголовком, не в стеклянной панели, чтобы не получалось стекло на стекло. Сортировка по дате последней работы, поэтому подписи «Сегодня», «Вчера», дата. Состояния «нажато» показаны у «+» и у карточки. Для Reduce Transparency брать непрозрачные значения из 01b.
