Критично (iOS 26 и macOS 26)
Адаптация контраста к фону под стеклом; капсульные формы, концентричные углам экрана; плотный вариант стекла над яркой схемой; сворачивание нижней панели при прокрутке; тинт акцента только на основной кнопке.
Можно упростить (iOS 17–25)
Преломление и «жидкая» морфинг-анимация → обычный blur материала (ultraThin / regular) + заливка 55–82%; блик → обводка 1 pt белая 22–70%; интерактивная подсветка при касании → лёгкое масштабирование 0.97. Формы и размеры остаются прежними.
