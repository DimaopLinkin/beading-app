## 1. Контекст и пользователь

- **Кто:** одна пользовательница, плетёт браслеты и украшения.
- **Техники:** на небольшом станке (loom) и в свободных руках (off-loom).
- **Как сейчас:** покупает книги со схемами, плетёт по бумаге.
- **Устройства:** iPhone 13 Pro Max (основное, рядом с рабочим местом) и MacBook
  (удобно рисовать/редактировать схемы на большом экране).
- **Боли, которые явно следуют из сценария:**
  - на бумаге легко потерять место (какой ряд, какая бусина);
  - нельзя быстро сгенерировать свою схему (из картинки/с нуля);
  - сложно посчитать количество бисера каждого цвета;
  - книгу неудобно держать открытой и отмечать прогресс.
- **Жёсткие требования проекта:** экран не гаснет во время работы, только
  портретная ориентация, светлая и тёмная тема, локальное хранение (drift),
  опциональная синхронизация iPhone ↔ Mac, редкие ненавязчивые комплименты-пасхалки.

## 2. Техники и что они требуют от схемы

Ключевое наблюдение: **техники делятся на «сеточные» и «маршрутные»**.
Сеточные описываются матрицей цветов на сетке определённой геометрии; маршрутные
требуют пошаговой инструкции и схемы прохода нити. Почти все существующие
инструменты поддерживают только сеточные.

| Техника | Тип | Геометрия сетки | Особенности для приложения |
|---|---|---|---|
| Станочное ткачество (loom) | сеточная | прямоугольная, ряды горизонтальные | самая простая модель; чтение ряд за рядом; нечётные/чётные строки не смещены |
| Квадратный стежок (square stitch) | сеточная | прямоугольная, как loom | визуально идентичен loom, плетётся без станка |
| Мозаика / пейот (peyote), ровный | сеточная | столбцы смещены на ½ бусины по вертикали | ряды читаются «через одну»; первый ряд = 2 ряда сетки; направление меняется каждый ряд |
| Пейот 2-drop / n-drop | сеточная | как пейот, бусины группами по n | нужна настройка «drop» |
| Трубчатый (tubular) пейот | сеточная | пейот, замкнутый в цилиндр, часто со спиральным сдвигом | нужна «бесшовная» сетка и учёт ступеньки (step-up) |
| Кирпичный стежок (brick) | сеточная | ряды смещены на ½ бусины по горизонтали | ряды могут уменьшаться (серьги-треугольники); нужен базовый ряд (ladder) |
| Ёлочка / ндебеле (herringbone) | полу-сеточная | пары бусин под углом | сетку можно отрисовать (столбцы пар), но цвета обычно простые; важна инструкция |
| Крестик / RAW (right angle weave), CRAW | маршрутная (частично сеточная) | ячейки из 4 бусин | можно описать сеткой «единиц», но нужен маршрут нити |
| Сетка (netting), спираль, жгуты, цветы, бисерные бусины | маршрутная | нет регулярной сетки | только пошаговые инструкции + картинки/фото этапов |
| Вязание с бисером (bead crochet rope) | сеточная (спиральная) | спираль с периодом N | отдельная модель (её делает JBead); вероятно, вне скоупа |

Вывод для модели данных: нужно абстрагировать **геометрию сетки** (rectangular,
peyote-offset, brick-offset, + параметры drop/tubular) от **содержимого**
(матрица ссылок на цвет палитры). Маршрутные техники хранятся как **пошаговая
инструкция** (шаги с текстом и изображениями), а не как сетка.

## 3. Обзор инструментов

Инструменты сгруппированы по классам. У каждого: что умеет, сильные и слабые
стороны, что из этого берём.

### 3.1 Мобильные приложения (iOS / iPadOS / Mac на Apple Silicon)

#### Loomerly: Loom, peyote & brick
- **Платформы:** iPhone, iPad, Mac (M1+). Оценка 4.8 (≈820 оценок).
- **Цена:** бесплатная загрузка, полная версия разовой покупкой (≈$30–75).
- **Техники:** loom, peyote, brick.
- **Функции:**
  - генерация схемы из фото с мастером настроек и мгновенным превью;
  - рисование с нуля, фоновое изображение для обводки;
  - палитры Miyuki, Toho, Preciosa (в т.ч. Toho Aiko), свои палитры;
  - фигуры (прямоугольник, овал, треугольник, звезда, сердце);
  - экспорт PDF и «word chart» (текстовая построчная раскладка: «3 × A, 2 × B…»);
  - **трекинг прогресса построчно** кнопками вверх/вниз;
  - данные только на устройстве.
- **Сильные стороны:** простой интерфейс (по отзывам «менее неуклюжий, чем у
  остальных»), быстрый фото-конвертер, разовая оплата без подписки, отзывчивый
  разработчик.
- **Слабые стороны (из отзывов):**
  - неточные цвета (красные выглядят коричневыми), правка цвета палитры меняет
    старые схемы;
  - нельзя переименовать цвет, добавить промежуточный оттенок; в каталогах
    не хватает цветов;
  - нет фигурного бисера (стеклярус, тилы);
  - нельзя выбрать, куда добавлять/удалять ряды; копирование только
    прямоугольником; мелкие ячейки трудно выделять;
  - можно заменить цвет, но нельзя поменять два цвета местами;
  - нет зеркалирования, комбинирования техник, длинной бахромы;
  - обновление однажды «испортило» старые схемы (добавило ряды);
  - нельзя прикрепить фото готового изделия.
- **Берём:** построчный трекер, word chart, фото → схема, палитры по производителям.
  **Учимся на ошибках:** версионирование формата схем и миграции; палитра схемы
  должна быть снимком, а не ссылкой на изменяемую глобальную палитру.

#### Threadologie: Bead Pattern (2025)
- **Платформы:** iPhone, iPad, Mac (M1+, не проверено), Vision Pro.
- **Цена:** подписка €2.99–5.99/мес.
- **Техники:** peyote (в т.ч. трубчатый), brick, loom.
- **Функции:** схема с нуля или из фото; встроенная библиотека бесплатных схем;
  цвета MIYUKI, TOHO, PRECIOSA, MATUBO с поиском по артикулу; **трекинг
  по бусине или по ряду со стрелками направления**; трубчатый режим;
  бахрома; оценка итоговых размеров по типу/размеру бисера; QR-код для
  открытия схемы; фото готового изделия на обложке; PDF с word chart,
  подсчётом бисера и легендой (Pro).
- **Сильные стороны:** самый полный современный набор для трекинга (стрелки
  направления, по бусине), расчёт размеров, фото изделия.
- **Слабые стороны:** подписка; мало отзывов (новое приложение); только английский
  интерфейс на старте; Mac-версия — порт iPad.
- **Берём:** стрелки направления при плетении, режим «по бусине», калькулятор
  размеров, обложка-фото готового изделия.

#### BeadPainter: Bead Patterns, 3D (2025)
- **Платформы:** iPhone, iPad, Mac (M1+), Vision Pro.
- **Цена:** freemium, Hobby $9.99, Pro $59.99.
- **Техники:** peyote, brick, loom.
- **Функции:** шаблоны изделий (кольца, серьги, браслеты, кулоны); карандаш,
  ластик, заливка, пипетка, Apple Pencil; выделение/перемещение/повтор,
  «штампы» из выделения; вставка/удаление/сдвиг рядов и столбцов, поворот;
  слои и подложка с прозрачностью; 1200+ цветов Delica с поиском по номеру
  и подбором ближайшего; симуляция покрытий (глянец, мат, металлик);
  **живое 3D-превью**; «ведомое плетение»: чек-лист материалов, уроки,
  построчные подсказки, маркер «последней бусины»; экспорт PDF/PNG.
- **Сильные стороны:** самый богатый редактор, 3D-превью, обучающий режим.
- **Слабые стороны:** платные ключевые функции (трекинг — в Hobby, PDF — в Pro),
  перегруженность для одной пользовательницы, свежий продукт без отзывов.
- **Берём:** маркер «последней бусины», чек-лист материалов перед стартом,
  штампы/повтор (для симметричных браслетов). 3D — в бонус.

#### BeadPatternCreator
- **Платформы:** iPhone, iPad, Mac (M1+). Цена: ≈$2.99 разблокировка.
- **Техники:** square, brick, peyote, 2-drop peyote, RAW.
- **Функции:** попиксельный редактор, 150+ штампов и бордюров с автообтеканием,
  заливка «все бусины этого цвета», undo/redo, копировать/вставить, поворот,
  отражение, **режим символов** (каждый цвет помечен символом), фото → схема,
  печать с подсчётом бисера.
- **Сильные стороны:** дёшево, поддержка 2-drop и RAW, символы для печати и
  дальтонизма/плохого освещения.
- **Слабые стороны:** нет трекинга прогресса, нет каталогов производителей,
  интерфейс устаревший.
- **Берём:** символьный режим, бордюры как готовые шаблоны.

#### Beads Creator и аналоги для термомозаики (Perler/Hama/Artkal)
- Редакторы пиксель-арта для термомозаики: импорт изображения, список бусин
  с количеством, экспорт/импорт файла схемы, круглые/шестиугольные основы.
- Реклама и лимиты на число схем в бесплатной версии.
- **Для нас:** нерелевантны по технике, но показательны в UX: простота,
  «список бусин» как отдельный экран, экспорт файла для бэкапа.

### 3.2 Десктопные программы

#### BeadTool 4 (Windows, macOS)
- **Цена:** разовая покупка, относительно недорого; есть пробная версия.
- **Техники:** peyote с офсетом от 1 до 9 (n-drop), loom, brick, RAW.
- **Функции:** фото → схема с выбором размера и числа цветов, палитра Delica
  по умолчанию, ручная правка, реалистичный (с бликами) или плоский рендер,
  экспорт PNG/JPG/GIF/BMP, список бисера с номерами и количеством, word chart.
- **Сильные стороны:** зрелый, «стандарт» для дизайнеров схем, хороший
  фото-конвертер, n-drop пейот.
- **Слабые стороны:** только десктоп, нет трекинга прогресса, интерфейс
  старого поколения, нет синхронизации с телефоном.
- **Берём:** параметр «drop» в пейоте, реалистичный рендер бусины как опцию.

#### Beadographer (Windows; macOS-версия заявлена производителем)
- **Техники:** loom, peyote, brick, square, RAW и др., плоские и трубчатые.
- **Функции:** конвертер изображений, большие библиотеки цветов, word chart,
  подсчёт материалов, печать.
- **Сильные стороны:** широкий набор техник, популярен у продающих схемы дизайнеров.
- **Слабые стороны:** платный, десктопный, крутая кривая обучения, нет мобильной
  связки и трекинга.

#### Easy Bead Patterns (Windows, macOS)
- Классический платный десктоп-редактор: loom, peyote, brick, square, RAW и др.,
  конвертер изображений, печать с легендой.
- Слабые стороны: устаревший UI, нет мобильной версии и трекинга.

#### DB-Bead (Windows, бесплатно) и JBead (кроссплатформенный, open source)
- **DB-Bead:** простой бесплатный редактор для loom/peyote/brick, популярен в
  русскоязычном сообществе; печать, подсчёт бисера.
- **JBead:** Java, открытый код (GPL); изначально для жгутов (bead crochet),
  умеет показывать схему, «развёртку» и симуляцию жгута; есть отчёт по цветам.
- **Сильные стороны:** бесплатны, лёгкие, понятная модель данных (JBead можно
  изучать как референс формата).
- **Слабые стороны:** только десктоп, нет фото-конвертера (DB-Bead) или он слабый,
  нет трекинга, нет облака.

### 3.3 Веб-инструменты

#### Stitch Fiddle (web + мобильное приложение)
- Универсальный редактор схем (вышивка, вязание, крючок, бисер: loom, peyote,
  brick). Конвертер изображений, палитры, печать/PDF, облачное хранение в
  аккаунте; в мобильном приложении есть **режим работы по схеме со счётчиком
  рядов и подсветкой текущего ряда**. Freemium, премиум — подписка.
- **Сильные:** работает везде через браузер, облако, хороший режим «работаю по схеме».
- **Слабые:** бисер — не основная специализация, нужен интернет и аккаунт,
  подписка на расширенные функции.

#### Bead Pattern Maker (bead-pattern.utils.com) и другие онлайн-конвертеры
- Бесплатные онлайн-генераторы «картинка → сетка бисера».
- **Сильные:** мгновенно, бесплатно.
- **Слабые:** нет сохранения/проектов, нет трекинга, ограниченные техники, реклама.

### 3.4 Смежные инструменты: «работа по готовой схеме» (книги, PDF)

Сюда относятся приложения для вязальщиц вроде **knitCompanion** и множество
счётчиков рядов (Row Counter). Они не генерируют схемы, а решают ту задачу,
которая у пользовательницы есть **уже сейчас**: работа по купленной схеме.

- Импорт PDF/фото страницы книги.
- Подсветка текущего ряда «линейкой»-полосой, сдвигающейся по нажатию.
- Маркеры, заметки, несколько счётчиков (ряды, повторы).
- Экран не гаснет, крупные кнопки «+1».
- **Вывод:** это самый короткий путь к реальной пользе. Даже до появления
  генератора приложение может закрыть боль «потеряла место в книге».

### 3.5 Нецифровые источники (текущий процесс)

- **Книги и журналы со схемами**, PDF-схемы с Etsy/VK/Pinterest/biser.info.
- Схемы маршрутных техник (жгуты, цветы, RAW) — фото этапов и рисунки прохода нити.
- **Вывод:** приложение должно уметь хранить такие схемы «как есть» (фото/PDF +
  трекинг поверх), а не только как собственную сетку.

## 5. Обязательные потребности (MVP)

Каждый пункт имеет ID для ссылок из плана разработки.

### A. Библиотека проектов
- **MUST-A1.** Список схем/проектов с превью, названием, техникой, статусом
  (идея / в работе / готово) и датой последней работы.
- **MUST-A2.** Создание, переименование, дублирование, удаление (с подтверждением).
- **MUST-A3.** Поиск и фильтр по технике и статусу.

### B. Схемы из книг (работа по чужой схеме)
- **MUST-B1.** Импорт схемы как изображения (камера, галерея/Фото, файлы) и PDF
  (с выбором страницы).
- **MUST-B2.** Просмотр с плавным зумом и панорамой (pinch-zoom), до мелких
  деталей на iPhone.
- **MUST-B3.** Трекинг поверх изображения: подсвечивающая «линейка» текущего
  ряда, двигается кнопками/свайпом; положение и масштаб линейки настраиваются.
- **MUST-B4.** Заметки к проекту.

### C. Редактор сеточных схем
- **MUST-C1.** Создание схемы с нуля: техника (loom/square, peyote, brick),
  ширина × высота.
- **MUST-C2.** Корректная отрисовка геометрии: прямоугольная, со смещением
  столбцов (peyote), со смещением рядов (brick).
- **MUST-C3.** Инструменты: кисть, ластик, заливка, пипетка, замена цвета
  во всей схеме, undo/redo.
- **MUST-C4.** Вставка/удаление ряда или столбца в выбранном месте.
- **MUST-C5.** Зеркалирование (горизонтальное/вертикальное) всей схемы или выделения.
- **MUST-C6.** Палитра схемы: добавить/переименовать/изменить цвет; цвет схемы
  хранится как снимок, правка глобального каталога не ломает старые схемы.

### D. Цвета и материалы
- **MUST-D1.** Встроенный каталог цветов основного бисера (минимум Miyuki Delica 11/0
  и Miyuki/Toho rocailles 11/0) с артикулом, названием и приблизительным RGB.
- **MUST-D2.** Поиск цвета по артикулу и подбор ближайшего цвета по RGB.
- **MUST-D3.** Подсчёт бисера по цветам (штуки и примерный вес/граммы).
- **MUST-D4.** Режим символов: у каждого цвета символ/буква для различения
  похожих оттенков и при плохом освещении.

### E. Генерация схем
- **MUST-E1.** Фото/картинка → сеточная схема: выбор техники, размера и
  числа цветов, ограничение палитры каталогом/своими цветами, превью до сохранения.
- **MUST-E2.** Генерация простых узоров по шаблонам (полосы, зигзаг, ромбы,
  шахматка, градиент) с параметрами — для браслетов это частый случай.

### F. Работа по своей схеме (режим плетения)
- **MUST-F1.** Отдельный режим «плетение»: текущий ряд подсвечен, прошлые
  притушены, будущие обычные.
- **MUST-F2.** Word chart для текущего ряда: «3 × A, 2 × B, 1 × A» с учётом
  направления (для peyote/brick направление меняется каждый ряд, нужна стрелка).
- **MUST-F3.** Отметка прогресса по ряду и, опционально, по бусине; крупные кнопки,
  удобные одной рукой.
- **MUST-F4.** Прогресс сохраняется мгновенно (локальная БД) и восстанавливается
  после закрытия приложения.
- **MUST-F5.** Экран не гаснет в режиме плетения (и, по требованию проекта, во
  всём приложении).

### G. Платформа и общие требования
- **MUST-G1.** iPhone (портрет) и macOS из одной кодовой базы Flutter.
- **MUST-G2.** Светлая и тёмная тема (системная + ручной выбор).
- **MUST-G3.** Офлайн-работа целиком; локальная БД (drift).
- **MUST-G4.** Русский интерфейс.
- **MUST-G5.** Экспорт/импорт проекта в файл (бэкап и перенос) — минимальный
  способ «синхронизации» до появления настоящей.
- **MUST-G6.** Версионированный формат данных и миграции БД (урок Loomerly).
- **MUST-G7.** Редкие ненавязчивые комплименты-пасхалки (in-app уведомления).

## 7. Чего делать не стоит

- **Подписки, реклама, лимиты** — приложение для одного человека, бесплатное.
- **Маркетплейс, соцсеть, аккаунты** — лишняя сложность и бэкенд.
- **Копирование чужих каталогов с фото бусин.** Брать только артикулы, названия
  и приблизительный RGB; не использовать фотографии производителей.
- **Полноценный «Photoshop»** (слои, кривые) — у конкурентов это главный источник
  перегруженности.
- **Свой бэкенд для синхронизации** — для двух Apple-устройств одного человека
  достаточно iCloud.

## 8. Выводы для плана разработки

1. **Ядро модели данных:** `Project` → (`GridPattern` | `ImagePattern` |
   `StepPattern`) + `Progress` + `Palette` (снимок цветов). Геометрия сетки —
   отдельная стратегия (`rectangular`, `peyote`, `brick`, параметры `drop`, `tubular`).
   Это хорошо ложится на чистую архитектуру: доменные сущности и use cases без
   зависимостей от Flutter, отрисовка геометрии — в presentation.
2. **Порядок поставки ценности** (предложение):
   1. Каркас: темы, портрет, wakelock, БД, библиотека проектов (A, G).
   2. Схемы из книг + трекинг линейкой (B) — польза уже на первом релизе.
   3. Редактор сеточных схем + режим плетения + word chart (C, F).
   4. Каталог цветов и подсчёт материалов (D).
   5. Генерация: шаблоны узоров, затем фото → схема (E).
   6. Бонусы: экспорт PDF, синхронизация, пошаговые инструкции, калькулятор.
3. **Хорошо тестируемые (TDD) чистые модули:** геометрия сеток и координаты
   бусин, word chart с направлением, квантование цветов (k-means / median cut в
   пространстве Lab, ΔE для подбора ближайшего цвета каталога), подсчёт
   материалов, генераторы узоров, миграции формата.
4. **Риски:**
   - точность цветов на экране vs реальный бисер (известная претензия ко всем
     конкурентам) — показывать артикул и название, а не только цвет;
   - производительность отрисовки больших сеток (100×300+) на Flutter —
     рисовать через `CustomPainter` с кешированием, не через тысячи виджетов;
   - синхронизация с iCloud из Flutter требует нативного плагина — вынести в
     отдельный этап;
   - лицензия на данные каталогов цветов.
5. **Валидация с пользовательницей:** до старта редактора стоит показать ей
   этот список и уточнить, по каким именно техникам и книгам она работает чаще
   всего, — это определит приоритет между B (книги) и C/E (свои схемы).
