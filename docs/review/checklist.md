# Чек-лист ревью

Ревьюер проходит каждый пункт. Категория замечания — код в скобках.

## Архитектура (`arch`)
- Импорты соблюдают направление слоёв (см. [../architecture.md](../architecture.md)); `scripts/check_architecture.sh` чистый.
- Use case делает одно дело; бизнес-логика не живёт в виджетах и Cubit.
- Новые зависимости регистрируются только в `lib/app/di.dart`.

## Тесты (`test`)
- Каждый критерий приёмки задачи покрыт тестом; тест проверяет поведение, а не реализацию.
- Есть граничные случаи: пустая схема, 1×1, максимальный размер, пустая палитра, повторный вызов.
- Нет `sleep`/реальных таймеров, `DateTime.now()`, `Random()` без сида в тестах.
- Пороги покрытия соблюдены.

## Корректность (`bug`)
- Иммутабельность сущностей, корректные `==`/`hashCode`.
- Исчерпывающие `switch` по sealed/enum.
- Асинхронность: нет потерянных `Future`, подписки закрываются, `BuildContext` после `await` проверяется на `mounted`.

## Данные (`data`)
- Изменение схемы drift — `schemaVersion`, миграция, тест миграции.
- Служебные поля синхронизации (`updated_at`, `deleted_at`, `device_id`) проставляются репозиторием.
- Исключения ловятся на границе `data` с `on`-типом и превращаются в `Failure`.

## UI (`ui`)
- Строки — только из ARB.
- Светлая и тёмная тема; цвета бусин не перекрашиваются темой.
- Тач-зоны ≥ 44pt, работает с крупным шрифтом (Dynamic Type), есть `Semantics` у интерактивных элементов.
- Только портрет; на macOS окно не ломается при ресайзе.

## Стиль (`style`)
- Имена по смыслу предметной области (ряд, бусина, палитра), без сокращений.
- Нет закомментированного кода, `print`, TODO без ссылки на задачу.
- `// ignore:` только с обоснованием.

## Производительность (`perf`)
- Отрисовка сетки не пересоздаёт объекты на каждый кадр; тяжёлые вычисления (квантование изображения) — в изоляте.

## Changelog (`changelog`)
- В PR есть `changelog.d/<ID>.md`, `task` совпадает с ID, `type` верный.
- Строки «Для пользовательницы» понятны без знания кода: что она увидит или сможет сделать, без названий классов и таблиц.
- Строки «Для разработки» упоминают миграции БД, изменения формата `.biser`, новые зависимости и разрешения iOS/macOS.
- `CHANGELOG.md` руками не правился.
