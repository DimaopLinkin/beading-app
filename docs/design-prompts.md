# Промпты для Claude Design

Порядок: сначала общий контекст (вставлять в начало каждого промпта), потом UI kit, потом экраны. Результат UI kit превращается в токены темы (задача T01b) и виджеты (T15 и экранные задачи). Экраны можно делать до или параллельно с кодом — задачи UI берут макеты, если они уже есть, иначе следуют UI kit.

## 0. Общий контекст (префикс к каждому промпту)

```text
Проект: «Бисер» — личное приложение для одной мастерицы бисероплетения. Она плетёт браслеты и украшения на небольшом станке и в свободных руках (мозаика/peyote, кирпичный стежок, ндебеле), сейчас работает по схемам из купленных книг.
Устройства: iPhone 13 Pro Max (428×926 pt, только портрет) — основное, лежит рядом во время плетения; MacBook — для создания и правки схем в окне 480–1000 pt шириной.
Сценарий использования: руки заняты бисером и иглой, телефон на столе, свет бывает вечерний. Нужны крупные кнопки внизу экрана, высокий контраст, минимум текста.
Язык интерфейса: русский.
Настроение: тёплое, рукодельное, спокойное, но современное (iOS 26 / Material 3). Без детскости и без «стоковых» иллюстраций. Акценты — как блеск стеклянного бисера.
Важно: цвета бусин в схемах — это данные, их нельзя тонировать темой. Интерфейс вокруг схемы должен быть нейтральным, чтобы не искажать восприятие цветов.
Нужны обе темы: светлая и тёмная, каждый экран — в обеих.
```

## 1. UI kit

```text
[общий контекст]

Сделай UI kit для приложения:
1. Палитра: нейтральные фоны и поверхности (светлая и тёмная тема), один основной акцент и один вторичный, цвета статусов (идея / в работе / готово), цвет подсветки текущего ряда и «притушенных» пройденных рядов, которые работают поверх любых цветов бисера. Дай значения hex и роли в терминах Material 3 ColorScheme.
2. Типографика: шкала из 6–8 стилей, крупный цифровой стиль для счётчика рядов (моноширинные цифры).
3. Сетка отступов 4/8 pt, радиусы, тени/возвышения для обеих тем.
4. Компоненты, все состояния (обычное, нажатое, выключенное, выбранное), обе темы:
   - кнопка основная / вторичная / текстовая, большая кнопка «следующий ряд» (≥56 pt) и «назад»;
   - карточка проекта в библиотеке (превью схемы, название, техника, статус-чип, дата, мини-прогресс);
   - чипы фильтров (техника, статус), поле поиска;
   - ячейка-бусина для трёх геометрий: прямоугольная (станок), пейот (столбцы со сдвигом на полбусины вниз), кирпичная (ряды со сдвигом на полбусины вбок); с символом внутри для режима символов;
   - образец цвета палитры: кружок цвета + буква-символ + артикул (например, «DB-0010») + название; выбранный и невыбранный;
   - строка word chart: «→ 3 × A, 2 × B, 1 × C» с цветными метками и стрелкой направления;
   - счётчик ряда: «Ряд 42 из 180» + кольцо или полоска прогресса;
   - «линейка» для схемы из книги: полупрозрачная горизонтальная полоса с ручками изменения высоты;
   - нижний лист (bottom sheet), диалог подтверждения удаления, тост/снэкбар;
   - баннер-комплимент: маленький, сверху, иконка-бусинка + одна строка тёплого текста, деликатный, исчезает сам;
   - панель инструментов редактора: кисть, ластик, заливка, пипетка, замена цвета, выделение, зеркало, отменить/повторить;
   - пустые состояния (нет проектов, нет цветов) — с маленькой графикой из бусин.
5. Иконка приложения: стилизованная бусина или нить с бусинами, читается в 60×60.
Выдай в виде одной страницы-спецификации с токенами, чтобы разработчик перенёс их в Flutter ThemeData.
```

## 2. Экраны

Каждый промпт начинается с общего контекста и фразы «Используй UI kit из предыдущего шага».

### 2.1 Библиотека проектов (MUST-A1–A3)

```text
Экран «Мои работы» — главный. Сверху заголовок и поиск, под ним чипы фильтров: техника (станок, мозаика, кирпич, другое) и статус (идея, в работе, готово). Список карточек проектов, отсортированных по дате последней работы; у «в работе» видна мини-полоса прогресса. Свайп по карточке — переименовать, дублировать, удалить (удаление с подтверждением). Плавающая кнопка «+» открывает лист «Новый проект» с вариантами: «Схема из книги (фото или PDF)», «Нарисовать схему», «Схема из картинки», «Узор по шаблону». Покажи: заполненный список, пустое состояние, результат поиска без совпадений. Обе темы.
```

### 2.2 Схема из книги: импорт (MUST-B1)

```text
Поток импорта схемы из книги: выбор источника (камера, Фото, Файлы); для PDF — сетка миниатюр страниц с выбором одной; затем экран обрезки/поворота фото страницы и поле названия проекта и выбор техники. Покажи все шаги, обе темы.
```

### 2.3 Схема из книги: работа с линейкой (MUST-B2–B4)

```text
Экран плетения по фото страницы из книги. Изображение занимает почти весь экран, зум щипком и панорама. Поверх — горизонтальная полупрозрачная «линейка», выделяющая текущий ряд; всё выше неё слегка притушено. Внизу крупная панель: «Ряд 17», кнопки «▲ назад» и «▼ следующий ряд» (большие, под большой палец), иконка настройки линейки (высота, шаг сдвига, цвет подсветки) и иконка заметок. Заметки открываются нижним листом. Покажи: обычный вид, приближенный вид, настройку линейки, заметки. Обе темы.
```

### 2.4 Режим плетения по своей схеме (MUST-F1–F4)

```text
Экран плетения по сеточной схеме (на примере мозаики/peyote и станка). Сверху компактная шапка: название, «Ряд 42 из 180», прогресс. В центре схема: текущий ряд подсвечен, пройденные притушены, будущие обычные; бусины текущего ряда при отметке «по бусине» заполняются по одной. Под схемой — word chart текущего ряда со стрелкой направления: «← 3 × A, 2 × B, 1 × A». Внизу крупные кнопки: «назад», «следующая бусина», «ряд готов». Переключатель «по ряду / по бусине», переключатель режима символов. Покажи начало ряда, середину ряда по бусине, режим символов, завершение проекта (с баннером-комплиментом). Обе темы.
```

### 2.5 Редактор сеточной схемы (MUST-C1–C6)

```text
Редактор схемы. Шаг 1 — лист создания: техника (станок/квадратный стежок, мозаика, кирпич), ширина и высота в бусинах, размер бисера, предпросмотр будущих размеров в сантиметрах. Шаг 2 — редактор: схема на весь экран с зумом, снизу панель инструментов (кисть, ластик, заливка, пипетка, заменить цвет, выделение, зеркало по горизонтали/вертикали, вставить/удалить ряд или столбец, отменить/повторить), над ней лента палитры схемы с текущим цветом. Нажатие на цвет в палитре — лист редактирования: название, цвет, выбор из каталога с поиском по артикулу. Покажи iPhone и широкое окно macOS (палитра сбоку). Обе темы.
```

### 2.6 Каталог цветов и материалы (MUST-D1–D4)

```text
Два экрана. (1) Каталог: вкладки производителей (Miyuki Delica, Miyuki Rocailles, Toho), поиск по артикулу и названию, сетка образцов; режим «подобрать похожий» — выбрать цвет и увидеть 5 ближайших с мерой похожести. (2) Материалы проекта: таблица цветов схемы — образец, символ, артикул, название, количество бусин, примерный вес в граммах, итог. Кнопка «Поделиться списком». Обе темы.
```

### 2.7 Генерация (MUST-E1–E2)

```text
Два мастера. (1) «Схема из картинки»: выбор фото → обрезка → параметры (техника, ширина в бусинах, число цветов, «только цвета каталога» / «только мои запасы», сглаживание) → живой предпросмотр «до/после» → сохранить. (2) «Узор по шаблону»: галерея шаблонов (полосы, зигзаг, ромбы, шахматка, градиент), параметры шаблона (ширина, высота, период, цвета) с живым предпросмотром браслета. Обе темы.
```

### 2.8 Настройки и «О приложении»

```text
Настройки: тема (системная/светлая/тёмная), «Не гасить экран», режим символов по умолчанию, производитель бисера по умолчанию, резервная копия (экспорт/импорт файла), синхронизация с iCloud (вкл/выкл, статус). «О приложении»: логотип, версия, короткая тёплая подпись. Обе темы.
```
