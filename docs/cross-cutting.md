# Сквозные требования и дополнения

## Пасхалки-комплименты (MUST-G7)

Цель — изредка, ненавязчиво сказать приятное. Не мешать работе, не повторяться, не превращаться в спам.

**Как выглядит.** Небольшой баннер сверху (в стиле in-app push): иконка-бусинка, одна строка текста, мягкое появление, исчезает сам через 5 секунд, закрывается свайпом вверх, не перекрывает кнопки плетения. Лёгкая вибрация `HapticFeedback.lightImpact`. Без системных push-уведомлений и без запроса разрешений.

**Когда показывается** (доменная `EasterEggPolicy`, чистая функция от событий, истории показов, `Clock` и `Random`):

| Триггер | Шанс | Пример |
|---|---|---|
| Проект отмечен как «готово» | 100% | «Ещё одна красота родилась. Ты волшебница» |
| Каждый 100-й отмеченный ряд | 30% | «Сотый ряд! Руки золотые» |
| Запуск приложения | 3% | «Привет! Сегодня отличный день, чтобы плести» |
| Долгая сессия (> 90 минут) | 50% | «Ты так увлечена — не забудь размять плечи» |
| Особые даты (день рождения, 8 марта, годовщина — задаются в настройках) | 100%, раз в день | Специальный текст |
| Секрет: 7 нажатий на логотип в «О приложении» | 100% | Записка от Дмитрия |

**Ограничения редкости:** не чаще одного раза в 3 дня (кроме «готово», особых дат и секрета), не больше одного за сессию, не во время первых 2 минут после запуска. Тексты не повторяются, пока не показаны все из группы (`easter_egg_log`).

**Тексты** — `assets/compliments/ru.json`, 40–60 штук по группам. Дмитрий может дописать свои без правки кода. Пользовательницу зовут **Настя**: часть текстов обращается к ней по имени («Настя, это шедевр»). Имя хранится в настройке с значением по умолчанию «Настя» (можно поменять в скрытом разделе), тексты используют плейсхолдер `{name}`.

**Тестирование:** политика целиком покрыта юнит-тестами с фиксированным `Random(seed)` и фейковым `Clock`; баннер — widget-тест, что он не перекрывает зону кнопок плетения.

## Экран не гаснет (MUST-F5)

- Пакет `wakelock_plus`, включается при старте приложения и при возврате на передний план (`AppLifecycleListener`), выключается при уходе в фон.
- В настройках переключатель «Не гасить экран», по умолчанию **включён**.
- На macOS тот же пакет не даёт уснуть дисплею.
- Логика «включить/выключить по жизненному циклу и настройке» — в `WakelockController` за интерфейсом `ScreenWakeLock`, тестируется с фейком.

## Только портрет (MUST-G1)

- iOS: `UISupportedInterfaceOrientations` в `Info.plist` — только `UIInterfaceOrientationPortrait`; дополнительно `SystemChrome.setPreferredOrientations([DeviceOrientation.portraitUp])` в `bootstrap`.
- macOS ориентации не имеет: окно стартует «портретным» 480×900, минимум 400×700, через `window_manager`. На широком окне контент центрируется с максимальной шириной, редактор может использовать ширину под панель палитры.

## Светлая и тёмная тема (MUST-G2)

- Material 3, `ThemeData` из токенов UI kit (см. [design-prompts.md](design-prompts.md)), режим: системный / светлый / тёмный, хранится в `settings`.
- Цвета бусин **никогда** не перекрашиваются темой. Меняются только фон под сеткой, линии сетки и подсветка ряда; контраст линий проверяется для обеих тем.
- Каждый экран проверяется в обеих темах (пункт DoD).

## Мои дополнения к плану

1. **Apple Developer Program (есть у Дмитрия).** Без него приложение на iPhone перестаёт открываться через 7 дней. С программой приложение ставится на её iPhone напрямую, а для Mac собирается подписанная и нотаризованная сборка. **В App Store Connect приложение не создаём и не публикуем** — раздача только Дмитрием напрямую (см. [release.md](release.md), задача T10).
2. **Сначала польза, потом красота.** По исследованию ни одно приложение не даёт отслеживать прогресс поверх фото страницы книги, а это именно её сценарий. Поэтому первый релиз (M1) — библиотека + схема из книги + линейка. Редактор и генерация — следом.
3. **Показать ей M1 до старта редактора.** Спросить, по каким техникам и книгам она плетёт чаще всего, — это может поменять приоритет M2/M3.
4. **Резервная копия.** Экспорт всего в один файл (MUST-G5) появляется в M2, задолго до синхронизации, чтобы не потерять прогресс при переустановке.
5. **Режим символов** (MUST-D4) и крупные кнопки: плетут при вечернем свете и одной рукой — кнопки «следующий ряд» внизу экрана, не меньше 56pt, работают и свайпом.
6. **Точность цвета.** Везде рядом с цветом показываем артикул и название — экранный цвет бусины всегда приблизителен.
7. **Данные только на устройстве и в её iCloud.** Никакой аналитики и сторонних сервисов.
8. **Название и иконка.** Рабочее имя «Бисер»; иконку можно сделать в Claude Design вместе с UI kit.

## Открытые вопросы к Дмитрию (не блокируют старт)

Ответы получены 2026-11-09:

- macOS на её MacBook — 26.x (не 27) → deployment target macOS 26.0, CloudKit `CKSyncEngine` доступен.
- Apple Developer Program оплачен, приложение не публикуется и записи в App Store Connect не будет → установка на iPhone напрямую (Ad Hoc), для Mac — Developer ID + нотаризация; CloudKit работает без App Store Connect (см. [data-and-sync.md](data-and-sync.md)).
- Имя — Настя (см. пасхалки).

Осталось (не срочно): даты для пасхалок (день рождения, годовщина) — задаются в скрытой настройке, в код не зашиваем; версия iOS на её iPhone (если ниже 18 — понизим target).
